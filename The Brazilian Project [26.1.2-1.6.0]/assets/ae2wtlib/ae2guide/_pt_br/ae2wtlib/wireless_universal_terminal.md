# Terminal Universal sem Fio

<ItemImage id="ae2wtlib:wireless_universal_terminal" scale="3" />

O <ItemLink id="ae2wtlib:wireless_universal_terminal" /> é uma combinação de vários [Terminais Sem Fio](wireless_terminals.md) num só item.

Todos os [Terminais Sem Fio do AE2WTLib](wireless_terminals.md) podem ser combinados num só terminal.

O <ItemLink id="ae2:wireless_terminal" /> do AE2 ***NÃO*** pode ser combinado num <ItemLink id="ae2wtlib:wireless_universal_terminal" />.


## A UI

O <ItemLink id="ae2wtlib:wireless_universal_terminal" /> adiciona um botão à UI do terminal,
que pode ser clicado com o botão esquerdo (e direito) para ir para o próximo (ou último) [Terminal Sem Fio](wireless_terminals.md).


## Melhorias

O <ItemLink id="ae2wtlib:wireless_universal_terminal" /> aceita as mesmas melhorias dos [Terminais Sem Fio](wireless_terminals.md) instalados.
Cada terminal instalado adiciona 2 espaços de melhoria.

## Armazenamento de energia

Adicionar terminais combina seus armazenamentos de energia,
então um <ItemLink id="ae2wtlib:wireless_universal_terminal" /> com dois terminais tem o dobro do armazenamento de energia de um [Terminal Sem Fio](wireless_terminals.md).
