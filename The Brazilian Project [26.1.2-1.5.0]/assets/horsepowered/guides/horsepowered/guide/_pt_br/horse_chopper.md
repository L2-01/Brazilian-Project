# Cortador de Cavalo

O Cortador de Cavalo é uma máquina de corte automatizada movida por um cavalo ou outra criatura. Ela corta troncos e outros itens continuamente sem intervenção manual.

<ItemImage id="horsepowered:chopper" scale="4" />
</Row>

## Preparo

1. Coloque o Cortador de Cavalo numa área com pelo menos 7x7 de espaço livre ao redor.
2. Conduza um cavalo (ou outra criatura válida) com um laço.
3. Clique com o botão direito no cortador segurando o laço para prender a criatura.
4. A criatura caminha em círculos, movendo o cortador.

## Verificando a Área de Trabalho

**Shift + clique direito** no cortador com a mão vazia para visualizar a área de trabalho exigida. Verde = livre, Vermelho = obstruído.

## Uso

1. Clique com o botão direito com troncos ou outros itens cortáveis para inseri-los.
2. A criatura presa corta os itens automaticamente.
3. Clique com o botão direito para extrair os itens de saída.

## Observações

- O cortador tem dois blocos de altura.
- Diferente do Bloco de Corte manual, nenhum machado é necessário.
- Funis podem inserir por cima ou pelos lados e puxar os itens prontos por baixo.
- Clique com o botão direito com a mão vazia para soltar a criatura presa.
- O piso sob o trajeto escala a velocidade de trabalho. Veja [Caminho e Velocidade](horse_path.md).
