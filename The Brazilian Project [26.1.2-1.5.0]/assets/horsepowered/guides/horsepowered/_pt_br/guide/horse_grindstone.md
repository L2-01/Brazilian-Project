# Rebolo de Cavalo

O Rebolo de Cavalo é uma máquina de moagem automatizada movida por um cavalo ou outra criatura andando em círculos ao redor dele.

<Row>
<ItemImage id="horsepowered:grindstone" scale="4" />
</Row>

## Preparação

1. Coloque o Rebolo de Cavalo numa área com pelo menos 7x7 de espaço livre ao redor.
2. Puxe um cavalo (ou outra criatura válida) com um laço.
3. Clique com o botão direito no rebolo segurando o laço para prender a criatura.
4. A criatura anda em círculos, movendo o rebolo.

## Verificando a Área de Trabalho

**Shift + clique direito** no rebolo com a mão vazia para visualizar a área de trabalho exigida. Verde = livre, Vermelho = obstruído.

## Uso

1. Clique com o botão direito com itens para inseri-los no rebolo.
2. A criatura presa mói itens automaticamente.
3. Clique com o botão direito para extrair os itens de saída.

## Observações

- Clique com o botão direito com a mão vazia para largar a criatura presa de volta a um laço.
- Se a criatura morrer ou escapar, um laço é largado.
- O piso sob o caminho escala a velocidade de trabalho, e uma pequena quantidade de obstruções (baús, funis etc.) é tolerada. Veja [Caminho e Velocidade](horse_path.md).
- Trabalhadores válidos por padrão: cavalos, burros, mulas e lhamas. Criaturas adicionais podem ser adicionadas via configuração.
