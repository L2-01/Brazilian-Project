# Bloco de Corte

O Bloco de Corte é uma estação de processamento manual para cortar troncos e outros itens usando um machado.

<Row>
<ItemImage id="horsepowered:chopping_block" scale="4" />
</Row>

## Uso

1. Coloque o Bloco de Corte.
2. Clique com o botão direito com um tronco ou outro item cortável para colocá-lo no bloco.
3. Clique com o botão direito com um machado para cortar o item.
4. Clique com o botão direito para coletar a saída.

## Custo de Fome

Cada golpe de machado custa uma pequena quantidade base de fome (configurável). Algumas receitas também somam seu próprio custo extra de fome sobre a base, e só o Bloco de Corte paga esse custo. O Cortador de Cavalo o ignora. O JEI mostra uma linha "Fome" nas receitas que têm um, então você identifica as caras numa olhada.

## Observações

- Machados podem levar dano de durabilidade ao cortar (configurável).
- Funciona com as mesmas receitas do Cortador de Cavalo, a menos que a receita seja marcada como só-cavalo.
- O corte manual leva mais golpes por receita que o corte a cavalo, por um multiplicador configurável; o JEI exibe a contagem real de golpes.
- As receitas de corte disponíveis podem ser vistas no JEI/EMI.
