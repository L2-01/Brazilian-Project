# Exemplos de Receitas

Um exemplo funcional de cada tipo de receita que um mod registra, escolhido dentre as receitas realmente carregadas
neste mundo. Uma caixa que renderiza é um renderizador funcionando; um *Couldn't find a handler for recipe* vermelho indica
um tipo que ainda não tem cobertura.

Nada aqui é escrito à mão, então as páginas seguem o que o pack mudar. A página de um mod só
aparece quando esse mod está instalado.
