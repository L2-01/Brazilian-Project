# Exemplos de Receitas

Um exemplo prático de cada tipo de receita que um mod registra, escolhido das receitas realmente
carregadas neste mundo. Uma caixa que desenha é um renderizador funcionando; um *Não foi possível
encontrar um manipulador para a receita* em vermelho nomeia um tipo que nada cobre ainda.

Nada aqui é escrito à mão, então as páginas seguem o que quer que um pacote mude. A página de um
mod só aparece quando aquele mod está instalado.
