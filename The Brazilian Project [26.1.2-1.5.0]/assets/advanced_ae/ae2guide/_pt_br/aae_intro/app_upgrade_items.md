# Melhorias do Provedor de Padrões Avançado

Itens do AdvancedAE que permitem melhorar provedores de padrões sem ter que mover todos os seus padrões e
melhorias.

## Melhoria de Provedor de Padrões Avançado

<ItemImage id="advanced_ae:adv_pattern_provider_upgrade" scale="3"></ItemImage>

Estas melhorias podem ser usadas em Provedores de Padrões comuns do AE e nos Provedores de Padrões Estendidos do ExtendedAE. Usá-la nessas
máquinas as melhora para a versão avançada mantendo a mesma quantidade de espaços que tinham antes. Isso
significa que você não perde os materiais usados para melhorar provedores comuns para provedores estendidos no processo.

## Melhoria de Capacidade do Provedor de Padrões Avançado

<ItemImage id="advanced_ae:adv_pattern_provider_capacity_upgrade" scale="3"></ItemImage>

Melhorias de capacidade são usadas para melhorar Provedores de Padrões comuns diretamente para um Provedor de Padrões Avançado com 36
espaços de padrão.
