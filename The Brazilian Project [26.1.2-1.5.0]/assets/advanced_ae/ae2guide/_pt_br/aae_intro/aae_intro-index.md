# Advanced AE!

O Advanced AE foca em melhorar a experiência do usuário ao lidar com seu Sistema ME e expandir as possibilidades de
sistemas de fim de jogo. Este mod permite melhorar provedores de padrões com a capacidade de empurrar itens para lados específicos
das máquinas-alvo e criar computadores multibloco que podem executar uma quantidade ilimitada de fabricações, compartilhando
co-processadores, enquanto houver armazenamento de fabricação, além de várias outras adições de qualidade de vida!
