# A Âncora para Cabos ME

<GameScene zoom="6" background="transparent">
  <ImportStructure src="../assets/assemblies/cable_anchor.snbt" />
  <IsometricCamera yaw="195" pitch="30" />
</GameScene>

Pequenos espigões decorativos montados em cabos que você pode usar para impedir que cabos se conectem, criar escadas com cabos ou fazer o cabo parecer
conectado às paredes ao redor. Também usados para fabricar a <ItemLink id="facade" />.

As âncoras para cabos ME impedem que conexões se formem no lado em que estão montadas.

Você pode escalá-las como uma escada.
