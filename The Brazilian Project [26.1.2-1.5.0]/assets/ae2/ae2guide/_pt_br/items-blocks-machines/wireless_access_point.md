# O Ponto de Acesso Sem Fio

<BlockImage id="wireless_access_point" p:state="has_channel" scale="8" />

Permite acesso sem fio via um <ItemLink id="wireless_terminal" />.
O alcance e o uso de energia são determinados com base no número de <ItemLink id="wireless_booster" /> instalados.

Uma rede pode ter qualquer número de pontos de acesso sem fio com qualquer número
de <ItemLink id="wireless_booster" /> em cada um, permitindo otimizar o uso de energia
e o alcance alterando seu esquema.

Requer um [canal](../ae2-mechanics/channels.md).

Também é usado para vincular [terminais sem fio](wireless_terminals.md)

# Amplificador de Alcance Sem Fio

<ItemImage id="wireless_booster" scale="2" />

Usado para aumentar o alcance do ponto de acesso sem fio.
