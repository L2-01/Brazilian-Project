# Célula de Visualização

<ItemImage id="view_cell" scale="2" />

Células de Visualização são usadas para filtrar a exibição dos [terminais](terminals.md). Você as particiona numa <ItemLink id="cell_workbench" />.

Por exemplo, digamos que você queira que um terminal exiba apenas uma seleção de materiais de construção de pedra. Particione a célula de visualização para aqueles
materiais e coloque-a num terminal, e apenas aqueles itens serão exibidos.

Células de visualização são aditivas: se você tiver uma célula de visualização para tábuas de carvalho e uma para pedregulho, colocar as duas exibirá
as tábuas e o pedregulho.
