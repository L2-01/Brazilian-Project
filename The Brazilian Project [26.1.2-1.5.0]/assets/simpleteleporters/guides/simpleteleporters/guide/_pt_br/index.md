# Simple Teleporters

Boas-vindas ao Simple Teleporters! Este mod oferece mecânicas de teletransporte fáceis de usar para o Minecraft.

## Recursos

<Row>
<Column>

### Rede de Teletransportadores

Crie uma rede de blocos de <ItemLink id="simpleteleporters:teleporter" /> vinculados por itens <ItemLink id="simpleteleporters:ender_shard" /> para viajar rápido entre locais. Aprimore para um <ItemLink id="simpleteleporters:enhanced_ender_shard" /> para viagem interdimensional!

</Column>
<Column>

### Teletransporte Pessoal

Use o <ItemLink id="simpleteleporters:hearth_crystal" /> para salvar um local de lar pessoal e teleportar de volta para ele de qualquer lugar.

</Column>
</Row>
