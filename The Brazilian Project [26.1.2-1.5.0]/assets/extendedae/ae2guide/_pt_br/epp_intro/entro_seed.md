# Semente de Entro

<Row>
<ItemImage id="extendedae:entro_seed" scale="4"></ItemImage>
</Row>

Essas sementes contêm forte energia de Entro. Clique com o botão direito num <ItemLink id="ae2:fluix_block" /> segurando uma Semente de Entro para transformá-lo numa [Drusa de Fluix Entroizado](./entro_budding.md).
Como alternativa, você pode usar um <ItemLink id="extendedae:crystal_assembler" /> para injetar a semente, mas ele produz uma [Drusa de Fluix Entroizado](./entro_budding.md) de qualidade inferior ao
método manual.
