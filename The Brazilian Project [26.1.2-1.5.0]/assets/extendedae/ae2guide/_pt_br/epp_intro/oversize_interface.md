# Interface ME Ampliada

<Row gap="20">
<BlockImage id="extendedae:oversize_interface" scale="8"></BlockImage>

A Interface ME Ampliada tem o mesmo número de espaços que uma <ItemLink id="extendedae:ex_interface" />, mas cada espaço pode guardar 16 vezes mais
itens por padrão (configurável). Isso significa que ela pode guardar 1024 (64 x 16) itens por espaço.

Multiplicadores específicos podem ser configurados para certos conteúdos de outros mods.
