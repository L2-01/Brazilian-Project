O Complemento de Proxy de Inventário fornece um ponto de acesso dedicado para que
sistemas de logística externos interajam com o armazenamento interno de uma máquina.

Aplicável a todas as máquinas com espaços de itens.

---

**Acesso Direcionado**

Por padrão, as máquinas podem expor todos os seus espaços a tubos e condutores.
O complemento de proxy permite designar um espaço específico que este
bloco representa.
Quaisquer itens inseridos ou extraídos pelo proxy irão diretamente
para o espaço selecionado na máquina.

Isso é útil para linhas de montagem complexas onde espaços específicos
de entrada ou saída precisam ser isolados.
