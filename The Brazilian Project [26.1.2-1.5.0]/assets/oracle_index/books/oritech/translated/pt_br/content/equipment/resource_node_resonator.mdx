title: Ressonador de Nó de Recurso
type: item
---

O ressonador de nó de recurso ajuda você a encontrar nós de recurso próximos de qualquer tipo para um [Extrator de Rocha Matriz](@oritech:bedrock_extractor).

Requer RF para usar.

- **Usar** faz a busca ou guia você até o resultado salvo.
- **Usar agachado** faz uma nova busca.
