Os nós de recurso são fontes infinitas de matérias-primas que podem ser mineradas usando o
[Extrator de Rocha Matriz](@oritech:bedrock_extractor). Esses nós são encontrados embutidos na rocha matriz
e são indestrutíveis.

Para encontrar esses nós, procure [Pedregulhos de Minério](@oritech:deepslate_platinum_ore) na superfície.
Eles marcam um nó de recurso diretamente abaixo, na rocha matriz.

<center>
<ModAsset location="oritech:area/resource_node" width={700} />
</center>

Existem nós de recurso para vários materiais, incluindo ferro, cobre, ouro,
níquel, platina, urânio e até gemas raras como diamantes.
Minerar esses nós exige que a broca alcance a camada de rocha matriz.

<center>
<ModAsset location="oritech:area/bedrock_extraction" width={1000} />
</center>

Um [Ressonador de Nó de Recurso](@oritech:resource_node_resonator) encontra o nó de recurso carregado mais próximo de qualquer tipo. Use agachado para buscar novamente depois de se mover para outra área.
