pesquisar e instalar melhorias permanentes no seu corpo.
Essas aumentações fornecem vários benefícios, desde
bônus passivos de atributos até habilidades totalmente novas.

# Pesquisa e Desenvolvimento

Para começar, entre no **Centro de Aumentação Cibernética** montado.
Isso abre a interface de pesquisa, onde você pode explorar e iniciar projetos.
Cada aumentação exige energia e recursos específicos, retirados do seu inventário pessoal ou
do armazenamento interno da máquina (acessível pela interface).

Muitas melhorias de nível alto exigem pesquisas anteriores, como mostrado na árvore tecnológica.

O centro funciona como um núcleo para as **Estações de Pesquisa**, construídas como extensões multibloco. A unidade principal suporta
até **três estações**, permitindo processamento paralelo.
*   Cada estação requer **3 Núcleos de Máquina**.
*   Uma estação conduz uma tarefa de pesquisa ativa por vez.

# Aplicação e Controle

Quando uma pesquisa é concluída, a aumentação fica disponível para instalação. O procedimento exige um custo único de recursos
para fundir permanentemente a tecnologia ao seu jogador.

Se você já tiver aumentações instaladas, pode carregá-las na máquina usando a função **Importar**
(botão inferior esquerdo da interface).

**Gerenciamento de Aumentações**:
Suas melhorias foram feitas para serem permanentes: elas não exigem manutenção nem custo contínuo de energia.
Porém, se uma habilidade se mostrar inconveniente (como **Visão dos Minérios** ou **Hipervelocidade**), ela pode ser alternada à vontade.

*   **Menu de Alternância**: segure a tecla de aumentação (**[G]** por padrão) para abrir a interface radial. Passe o mouse sobre o
aumento desejado e solte para alternar o estado dele.
*   **Remoção**: embora as aumentações sejam feitas para serem permanentes, elas podem ser removidas se necessário.
Note que os recursos investidos na instalação não são reembolsáveis.

**Informações para Desenvolvedores de Modpacks**

As aumentações do Oritech são totalmente orientadas a dados e configuráveis, permitindo ampla personalização por datapacks.

*   **Aumentos de Modificador**: alteram atributos de entidades (ex.: velocidade, alcance, vida).
*   **Aumentos de Efeito**: aplicam efeitos de status semelhantes a poções.
*   **Aumentos Personalizados**: implementam lógica única (ex.: Visão dos Minérios). Eles podem ser referenciados em datapacks, mas exigem um mod
Java para a lógica subjacente.

Os aumentos existentes podem ser modificados ou desativados, e novos podem ser definidos via JSON.
*   **Exemplo de Definição**: [Aumento de Dano de Ataque (GitHub)](https://github.com/Rearth/Oritech/blob/1.21/fabric/src/main/generated/data/oritech/recipe/augment/attackdamage.json)
*   **Local das Texturas**: `oritech/textures/gui/augment`

Lembre-se de incluir entradas de tradução para quaisquer adições personalizadas.
