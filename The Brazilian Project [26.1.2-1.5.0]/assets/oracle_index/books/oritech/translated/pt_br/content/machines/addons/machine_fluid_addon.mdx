---
title: Complemento de Fluido
id: oritech:machine_fluid_addon
type: block
---

O Complemento de Fluido habilita recursos de processamento de fluidos para máquinas
que normalmente só lidam com itens.

Ele é especificamente necessário para as seguintes operações:
- Para a [Centrífuga](@oritech:centrifuge) processar e
separar fluidos.
- Para o [Porto de Drones](@oritech:drone_port) transportar líquidos.

<Callout variant="info">
    Uma vez acoplado, a máquina ganha armazenamento de fluido e os espaços
    de fluido correspondentes ficam visíveis na interface do usuário.
</Callout>
