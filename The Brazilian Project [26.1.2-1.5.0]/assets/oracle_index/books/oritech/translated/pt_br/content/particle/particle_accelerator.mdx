title: Acelerador de Partículas
id: oritech:particle_accelerator
type: block
---

O controlador do acelerador de partículas é o ponto de entrada das partículas. Itens inseridos neste bloco são transformados em partículas.
Os resultados das colisões podem ser coletados no espaço de saída.

Um [anel guia](@oritech:accelerator_ring) reto precisa ser colocado logo atrás do controlador, virado para o lado,
com o visual alinhado corretamente. Qualquer item pode ser inserido no controlador para ser usado como partícula.

Uma vez inserida, a partícula viaja por uma rota definida pelos anéis guia.

Para informações detalhadas sobre a mecânica de aceleração de partículas, veja o [guia do acelerador de partículas]($particle_accelerator).
