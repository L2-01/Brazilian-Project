Transporta líquidos entre máquinas e tanques. A taxa de transferência padrão é de 0,5 baldes a cada 3 tiques. Tubos de fluido não têm armazenamento interno.

## Uso
Conecte os tubos a qualquer bloco que manipule fluidos. Clique com o botão direito na parte relevante do tubo para alternar a extração. Nenhuma chave é necessária.
Porém, uma chave pode ser usada para desativar conexões de tubo.

## Variantes
*   **Padrão**: modelo de tubo básico
*   **Com Estrutura**: versão de bloco sólido para integração em paredes
*   **Duto**: estilo estético alternativo. Variantes em duto não se conectam diretamente a máquinas, apenas a outros tubos.
