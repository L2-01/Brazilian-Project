O controlador do reator é o bloco principal de controle do reator. Este bloco precisa ser colocado uma vez em algum lugar das paredes.
Interaja com ele para montar ou atualizar o reator.

A interface mostra o status atual do reator, junto com as temperaturas dos componentes e estatísticas.
A interface só mostra a primeira camada do interior.

<Callout variant="danger">
    Sempre monitore os níveis de calor do seu reator. Um superaquecimento prolongado desencadeará um derretimento nuclear,
    causando dano estrutural significativo.
</Callout>

Para informações detalhadas sobre a mecânica do reator, veja o [guia do reator nuclear]($reactor/introduction).
