---
title: Guia do Usuário
---

O Oracle Index é um mod de documentação que roda no lado do cliente dentro do jogo, pensado como uma visualização interna do conteúdo do [moddedmc.wiki](https://moddedmc.wiki/).

Os desenvolvedores de mods podem optar por incluir suas wikis nos mods e então usar o mod Oracle Index para exibi-las dentro do jogo. Pressione a tecla de atalho da wiki (padrão [H]) para abrir a tela do Oracle Index.
Você não precisa de um item de livro especial nem nada do tipo. Ao sair da tela, ele se lembra de onde você parou.

Você só consegue visualizar a documentação de um mod se o mod estiver instalado e o desenvolvedor tiver optado por incluir sua documentação do moddedmc.wiki como wiki do Oracle Index também.

## Alternando entre Mods
No lado esquerdo da tela, você verá a barra de navegação do mod atualmente selecionado. Para trocar para outro mod, basta clicar na barra de título do mod acima da barra de navegação.
Um menu suspenso se abrirá, onde você pode selecionar qual mod explorar.

## Links de Itens
Os desenvolvedores podem adicionar links de wiki a itens do jogo. Se houver uma página de wiki disponível para um item, você verá um pequeno extra na tooltip do item.
Segure a tecla [ALT] para abrir a entrada da wiki correspondente ao visualizar a tooltip do item.

## Idioma
O Oracle Index usa automaticamente o conteúdo traduzido para o seu idioma exato do Minecraft quando a wiki o fornece. Conteúdo das páginas, metadados de navegação, títulos de página, controles integrados, callouts e mensagens de status podem ser traduzidos.

As páginas traduzidas espelham o caminho da página base em `translated/<locale>/` em wikis de schema 1, ou `.translated/<locale>/` em wikis legadas. Quando uma página traduzida ou um arquivo de metadados está ausente, o Oracle Index recorre ao recurso do idioma base.

Atualmente a pesquisa indexa o texto das páginas no idioma base. Os resultados ainda abrem a página traduzida quando há uma disponível, e os títulos exibidos usam o idioma ativo.
