# Genes de Abelha

## Produtividade

Os genes do Productive Bees importam principalmente para abelhas soltas no mundo. Dentro do apiário, o que conta é a **Produtividade**.

Um gene de Produtividade mais alto significa que a abelha produz mais a cada lote, e ele se soma à [melhoria de Produtividade](upgrades.md#productivity).

## Verificando uma Abelha

Passe o mouse sobre uma abelha na [Caixa de Abelhas](modules.md#bee-box) para ver seus genes.

Cruze abelhas para Produtividade maior e aproveite o máximo do seu apiário.
