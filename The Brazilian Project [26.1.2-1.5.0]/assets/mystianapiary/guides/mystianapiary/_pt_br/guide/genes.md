# Genes de Abelha

## Produtividade

Os genes do Productive Bees importam sobretudo para abelhas soltas no mundo. Dentro do apiário, o que conta é a **Produtividade**.

Um gene de Produtividade mais alto faz a abelha produzir mais a cada lote, e se soma à [Melhoria de Produtividade](upgrades.md#productivity).

## Verificando uma Abelha

Passe o mouse sobre uma abelha na [Caixa de Abelhas](modules.md#bee-box) para ver seus genes.

Cruze as abelhas para obter Produtividade maior e tirar o máximo do seu apiário.
