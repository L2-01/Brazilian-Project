# Recursive AE2 Pattern Provider

## ✨ Recursos Principais

### 🎯 Geração Automática de Padrões
- **Dependências Inteligentes**: Cria automaticamente padrões de ingredientes de fabricação faltantes em tempo real.
- **Lógica Recursiva**: Rastreia cadeias profundas de dependências até a profundidade máxima configurada.
- **Descoberta de Receitas**: Só constrói padrões para itens com receitas válidas e solucionáveis.
- **Suporte Universal**: Gera padrões de dependência para todos os componentes de fabricação padrão.
- **Compatível com**: AE2, Extended AE2, Advanced AE e ExtendedAE-Plus!

### ⚙️ Integração Perfeita com a GUI
- **Alternância Direta no Terminal**: Alterne a recursão diretamente dentro do Terminal de Codificação de Padrões usando um botão dedicado (configurável via `enableEncodingGuiToggle`).
- **Focado em Padrões de Fabricação**: Integrado perfeitamente à codificação de Padrões de Fabricação, permanecendo oculto para modos que não são de fabricação.
- **Método Alternativo por Receita**: Suporta converter padrões existentes via receitas de bancada (`Pattern + Iron Ingot`).

### 🎨 Feedback Visual Limpo
- **Dicas Nativas**: Exibe um rótulo `Recursive` discreto combinando com o design de dicas nativo do AE2.
- **Marcação Persistente**: Recodificar padrões no terminal mantém seu status recursivo sem passos extras.
