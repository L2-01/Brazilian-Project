# Recursive AE2 Pattern Provider

## 💡 Cenário de Exemplo

### Configuração AE2 Tradicional
Para autofabricar uma Picareta de Ferro, tradicionalmente você deve codificar e registrar manualmente:
1. Padrão de Picareta de Ferro
2. Padrão de Graveto
3. Padrão de Tábua de Madeira (de Troncos)
4. Padrão de fundição de Lingote de Ferro (de Ferro Bruto)
5. Preencher manualmente os Provedores de Padrões com cada subreceita...

### Com o Recursive AE2 Pattern Provider
1. Abra o **Terminal de Codificação de Padrões**, ative a alternância **Padrão Recursivo** e codifique UM padrão de Picareta de Ferro.
2. Insira-o no seu Provedor de Padrões.
3. **Todos os subpadrões necessários são gerados automaticamente!**

O mod rastreia toda a árvore de fabricação através de tábuas, gravetos e partes intermediárias, mantendo sua rede limpa e eliminando a fabricação repetitiva de padrões.
