# Extração de seiva

<ItemImage id="iska_utils:sap" />

## Extração manual

- Use um **Drenador** num tronco de borracha cheio para extrair **Seiva**.
- O **Drenador Elétrico** é a variante energizada (veja o tooltip do item para o uso).

## Automação

- O **Extrator de Seiva de Seringueira** pode extrair seiva automaticamente de troncos de borracha adjacentes.
