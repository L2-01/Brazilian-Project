# Módulo Lógico

<ItemImage id="iska_utils:logic_module" />

Expande a capacidade em máquinas compatíveis.

| Máquina | Papel |
| ------- | ---- |
| **Fabricador de Padrões Aprimorado** | Cada módulo adiciona **+1 slot de padrão** e **+1 página de variáveis** (**18** teclas). Máx. de instalação padrão: **4**. |

Capacidade base do Aprimorado sem módulos: **6** padrões e **1** página de variáveis (18 teclas).
