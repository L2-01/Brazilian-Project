# Módulo Lógico

<ItemImage id="iska_utils:logic_module" />

Expande a capacidade em máquinas suportadas.

| Máquina | Papel |
| ------- | ---- |
| **Fabricador de Padrões Aprimorado** | Cada módulo adiciona **+1 espaço de padrão** e **+1 página de variáveis** (**18** teclas). Máximo instalado padrão: **4**. |

Capacidade base Aprimorada sem módulos: **6** padrões e **1** página de variáveis (18 teclas).
