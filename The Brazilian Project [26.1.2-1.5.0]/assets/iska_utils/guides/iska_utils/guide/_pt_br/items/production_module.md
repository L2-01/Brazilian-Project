# Módulo de Produção

<ItemImage id="iska_utils:production_module" />

Aumenta a vazão ou o tamanho do lote em máquinas compatíveis.

| Máquina | Papel |
| ------- | ---- |
| **Fabricador de Padrões** | Mais fabricações rodando ao mesmo tempo. |
| **Gerador Entropizado** | Criaturas extras por ciclo de spawn (por módulo na pilha). |
| **Purificador de Radiação** (quando presente) | Passadas de purificação mais fortes. |
