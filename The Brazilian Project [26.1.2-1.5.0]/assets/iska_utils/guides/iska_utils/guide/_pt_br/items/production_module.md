# Módulo de Produção

<ItemImage id="iska_utils:production_module" />

Aumenta a vazão ou o tamanho do lote em máquinas suportadas.

| Máquina | Papel |
| ------- | ---- |
| **Fabricador de Padrões** | Mais fabricações rodando ao mesmo tempo. |
| **Gerador Entropizado** | Criaturas extras por ciclo de geração (por módulo na pilha). |
| **Purificador de Radiação** (quando presente) | Passadas de purga mais fortes. |
