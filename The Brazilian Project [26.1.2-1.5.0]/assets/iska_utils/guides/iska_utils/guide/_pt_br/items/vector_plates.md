# Placas vetoriais

<ItemImage id="iska_utils:slow_vect" />

Placas estilo esteira que empurram entidades na direção para a qual estão viradas. Os ícones do inventário mostram um selo de **farm de criaturas** ou **jogador** para você distinguir as duas linhas.

## Placas de farm de criaturas

IDs sem `player_` (`slow_vect` … `ultra_vect`). Empurram apenas **criaturas** (não-jogadores).

- **Lenta / Moderada / Rápida / Extrema / Ultra** — níveis maiores movem entidades mais rápido.

## Placas de jogadores

IDs com `player_` (`player_slow_vect` … `player_ultra_vect`). Empurram **jogadores** da mesma forma, mas ignoram criaturas.

## Níveis de velocidade

Cada nível de velocidade é um bloco diferente. Níveis maiores são melhorias dos menores.
