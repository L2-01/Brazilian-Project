# Ovo Entrópico

<ItemImage id="iska_utils:entropic_egg" />

## Uso

Use numa **criatura** no mundo. Em caso de sucesso, você recebe o **ovo gerador** daquela criatura. Se nada acontecer, a interação não é válida para aquele alvo.

## Relacionados

- **Solo Entrópico** — spawns na escuridão com fortalecimento; veja essa página para regras de propagação e luz.
- **Aglomeração Entrópica** — conversão instantânea de trechos de solo.
