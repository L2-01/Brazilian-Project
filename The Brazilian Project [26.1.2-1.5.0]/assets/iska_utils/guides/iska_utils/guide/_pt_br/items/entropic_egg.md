# Ovo Entrópico

<ItemImage id="iska_utils:entropic_egg" />

## Uso

Use numa **criatura** no mundo. Em caso de sucesso, você recebe o **ovo gerador** daquela criatura. Se nada acontecer, a interação não é válida para aquele alvo.

## Relacionados

- **Solo Entrópico** — gerações na escuridão com empoderamento; veja aquela página para regras de espalhamento e luz.
- **Aglomeração Entrópica** — conversão instantânea de manchas de solo.
