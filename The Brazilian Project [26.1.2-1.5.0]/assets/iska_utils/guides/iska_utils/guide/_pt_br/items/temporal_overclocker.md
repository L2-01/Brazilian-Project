# Acelerador Temporal

<ItemImage id="iska_utils:temporal_overclocker" />

## O que faz

- Vincula-se a blocos próximos para acelerar seus tiques / processamento (comportamento exato conforme o tipo de bloco suportado).

## Chipset

- Use itens **Chipset do Acelerador Temporal** para configurar ou impulsionar a máquina (veja a GUI).

## Melhoria entrópica

- **Espaço de melhoria** (à esquerda do botão de Aceleração): insira um <ItemImage id="iska_utils:entropic_clock" /> **Relógio Entrópico** para aumentar o fator máximo de aceleração. Veja **Módulos** → **Relógio Entrópico**.
- **Espaço de combustível** (à direita do botão de Aceleração): insira **Gota de Entropia**; as gotas são convertidas em carga interna de entropia (porcentagem mostrada abaixo do espaço). Entropia é consumida ao acelerar blocos vinculados quando o relógio está instalado.
