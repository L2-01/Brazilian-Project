# Módulos vetoriais (aceleração)

<ItemImage id="iska_utils:slow_module" />

## Uso

- Componentes de fabricação para o **Amuleto Vetorial** e equipamentos vetoriais relacionados (níveis maiores para amuletos de nível maior).
- **Melhorias de velocidade** quando instalados em máquinas que os aceitam:
  - **Ventilador Modular** — empuxo mais rápido.
  - **Fabricador de Padrões** — tempo de fabricação menor.
- Eles **não** são instalados em placas vetoriais.

Níveis maiores significam efeito de velocidade mais forte.
