# Interações do Terminal

Os terminais exibem a energia armazenada como este *fluido verde*.

![FE_GUI](../pic/fe_terminal.png)

Ele não é um fluido de verdade, e você não pode usar baldes para enchê-lo.

Você pode usar um contêiner de energia, como baterias e ferramentas elétricas, para encher/drenar energia nele/dele.

![FE_GUI2](../pic/fe_terminal2.png)
