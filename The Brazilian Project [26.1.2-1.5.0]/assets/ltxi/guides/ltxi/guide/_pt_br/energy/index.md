# Energia

Energia Comum (EC) é o jeito da LTX Industries de se referir à API de energia usada pelo NeoForge. Você pode conhecê-la
como Forge Energy, FE, Redstone Flux, RF, etc.

<Color id="energy">Este tom de azul-claro</Color> é usado como pista de contexto onde quer que energia seja
usada, referenciada, melhorada etc.

Antes de mergulhar na árvore tecnológica, você vai precisar produzir energia. Idealmente, você também vai querer algum
armazenamento de energia. No início dá para se virar só com os buffers de energia internos das máquinas, mas eles se
tornam insuficientes bem rápido.
