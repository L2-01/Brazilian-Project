# Energia

Energia Comum (EC) é a forma da LTX Industries de se referir à API de energia usada pelo NeoForge. Você pode conhecê-la como Forge Energy,
FE, Redstone Flux, RF, etc.

<Color id="energy">Este tom de azul-claro</Color> é usado como pista de contexto onde quer que energia seja
usada, referenciada, melhorada, etc.

Antes de mergulhar na árvore de tecnologia, você vai precisar produzir energia. Idealmente, você também vai querer algum armazenamento de energia.
Você pode se virar só com os buffers de energia embutidos das máquinas no começo, mas eles se tornarão insuficientes bem rápido.
