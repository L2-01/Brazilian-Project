# Elementos Compostos

Alguns compostos elementares são encontrados ou prontamente acessíveis a partir de recursos naturais. Como os elementos
base, estes podem ser extraídos com algum processamento de máquina.

## Metano

<ItemImage id="portable_tank" components="limacore:fluid={id:'ltxi:methane', amount:16000}" scale="2" />

O Metano é um gás hidrocarboneto abundante encontrado nos Pântanos da Superfície. Requer o
[Depurador Atmosférico](../machines/resource/atmospheric_scrubber.md) para ser colhido. É uma fonte de combustível
eficiente, bem como a matéria-prima para polímeros avançados e compostos de silicone.

## Sulfurina

<ItemImage id="portable_tank" components="limacore:fluid={id:'ltxi:sulphurine', amount:16000}" scale="2" />

A Sulfurina é o gás atmosférico do Nether. As condições de outro modo impossivelmente secas do Nether permitem que este
gás permaneça estável e não decaia para enxofre elementar. O [Laboratório Químico](../machines/processing/chem_lab.md)
pode reagir Sulfurina com Água para formar Ácido Sulfúrico, e ela também é usada para solidificar Óleo de Silicone em
borracha.

## Água do Mar

<ItemImage id="portable_tank" components="limacore:fluid={id:'ltxi:sea_water', amount:16000}" scale="2" />

A água dos oceanos da Superfície tem uma alta concentração de cloro vindo da flora marinha. Um Depurador Atmosférico pode
colher a água do oceano, e o Cloro pode então ser extraído via
[Eletrocentrífuga](../machines/processing/electrocentrifuge.md).

## Amônia

<ItemImage id="portable_tank" components="limacore:fluid={id:'ltxi:ammonia', amount:16000}" scale="2" />

A Amônia é um composto tóxico de nitrogênio-hidrogênio usado para cultivar certa flora exótica no
[Jardim Bio/ARU](../machines/resource/digital_garden.md) e para armas de gás sombrio. Mais importante, é usada na linha
de processamento do metal Rênio.
