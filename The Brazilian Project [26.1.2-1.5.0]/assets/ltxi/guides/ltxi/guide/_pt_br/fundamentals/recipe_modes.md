# Modos de Receita

Algumas receitas de máquina compartilham combinações de entrada que tornariam impossível fabricar ambas. É para isso que servem os Modos
de Receita. Você pode pensar neles como subtipos de receita, ou talvez um ingrediente-'chave' especial para especificar qual receita será
usada. Você pode alterná-los à vontade, mas é *altamente recomendado* dedicar uma máquina a um modo de receita. Seria uma
surpresa desagradável deixar uma pilha de Frutas de Fagulha e voltar para encontrar Pigmento Chartreuse Elétrica em vez de Pó de Sódio porque
você esqueceu de trocar de Extração de Elemento para Extração de Corante.

## Seleção

![](../assets/recipe_modes_button.png)

Máquinas compatíveis com modos de receita terão o botão de seleção na barra lateral inferior esquerda. Este botão
também mostra uma prévia do ícone, assim como o nome ao passar o mouse por cima.

## Disponibilidade

![](../assets/recipe_modes_screen.png)

Cada tipo de receita (e máquina) pode ter até 23 modos de receita selecionáveis; o primeiro botão é sempre reservado para Nenhum.
Os modos selecionáveis vêm de duas fontes: os modos padrão atribuídos aos Tipos de Receita, e os adicionais concedidos por
[módulos de melhoria](../fundamentals/upgrade_system.md). Modos de receita padrão estão sempre disponíveis. Modos de receita concedidos por
módulo de melhoria requerem que o módulo permaneça instalado e serão redefinidos para Nenhum se o módulo for removido.
