# <Color id="gold">NauTec 2</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="aquatic_catalyst" scale="2"/>
  Um mod de tecnologia oceânica que roda a feixes de laser.
</Column>

As máquinas do NauTec funcionam com energia de laser (AP) disparada de um bloco para outro. Este guia cobre criar e rotear feixes, as máquinas que os usam, criar bactérias para recursos, instalar aprimoramentos no seu corpo e o submersível Explorador Marinho.

Novo no mod? Leia a [Introdução](getting_started/introduction.md), depois [Energia de Laser](getting_started/laser_power.md) para disparar seu primeiro feixe.
