# Fundidor

<BlockImage id="melter" scale="4" />

O **Fundidor** transforma entradas sólidas em fluido fundido para sua cadeia de reator ou outras máquinas.

## Controles

- **Espaço de entrada**: coloque itens processáveis aqui (veja o JEI para receitas válidas).

- **Barra de progresso**: mostra o progresso da receita atual; **clique nela no JEI** (quando instalado) para abrir as receitas correspondentes.

- **Tanque de fluido**: passe o mouse para ver o tipo e a quantidade de fluido. O **D** abaixo do tanque despeja o fluido armazenado.

- **Botão de engrenagem de redstone**: alterna o comportamento de redstone (ignorar, baixo, alto etc. — os rótulos são atualizados no botão). Passe o mouse para ver o nome do modo ativo.
