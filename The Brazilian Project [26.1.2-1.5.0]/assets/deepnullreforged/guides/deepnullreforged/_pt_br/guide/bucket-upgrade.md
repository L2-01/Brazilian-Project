# Melhoria de Balde

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="deepnullreforged:fluid_upgrade" />
</Column>

A Melhoria de Balde permite que um DeepNull use baldes armazenados e recipientes de fluido compatíveis diretamente dos espaços de itens.

## Disponibilidade

- Somente DeepNull
- Todos os níveis

## Notas

- Separada do DampNull, que é armazenamento dedicado por tanques
- Usada pela Bancada Null para converter DeepNulls em DampNulls
