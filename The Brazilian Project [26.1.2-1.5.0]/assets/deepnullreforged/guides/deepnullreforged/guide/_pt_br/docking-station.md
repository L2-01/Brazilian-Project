# Estação de Acoplagem

<Column alignItems="center" fullWidth={true}>
  <BlockImage id="deepnullreforged:deepnull_dock" />
</Column>

A Estação de Acoplagem DeepNull comporta um DeepNull ou DampNull e o expõe à automação.

## Capacidades

- Automação de itens para DeepNulls acoplados
- Automação de fluidos para DampNulls acoplados
- Automação de energia para DeepNulls acoplados com Melhoria de Energia
- Automação de produtos químicos para DampNulls acoplados com Melhoria de Produto Químico

## Observações

- DampNulls geradores acoplados usam o buffer da estação para a saída dos itens gerados
- Melhorias de Ender podem se vincular a Nulls acoplados entre dimensões
