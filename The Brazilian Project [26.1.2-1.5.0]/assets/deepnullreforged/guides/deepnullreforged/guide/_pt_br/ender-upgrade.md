# Melhoria de Ender

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="deepnullreforged:ender_upgrade" />
</Column>

Vincula um DeepNull ou DampNull a um Null acoplado do mesmo tipo e nível, e então espelha o armazenamento acoplado entre dimensões.

## Disponibilidade

- DeepNull ou DampNull
- Todos os níveis

## Como Usar

1. Shift + clique direito num Null acoplado com a Melhoria de Ender para vinculá-la.
2. Instale a melhoria vinculada em outro Null do mesmo tipo e nível.
3. O Null instalado espelha a fonte acoplada até que o Null de origem seja removido ou a estação seja quebrada.
