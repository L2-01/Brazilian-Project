# Gerador de Pedra

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="deepnullreforged:stone_generator_upgrade" />
</Column>

Gera uma variante de pedra selecionada dentro de um DampNull enquanto há água e lava presentes. Os fluidos são necessários, mas não são consumidos.

## Disponibilidade

- Somente DampNull
- Todos os níveis

## Tipos de Pedra

- Pedregulho
- Diorito
- Andesito
- Granito
- Pedregulho de Ardosiabissal
- Tufo

## Diferenças por Nível

| Nível | Taxa |
| --- | ---: |
| Redstone | 1/s |
| Lápis-Lazúli | 2/s |
| Ferro | 3/s |
| Ouro | 4/s |
| Diamante | 5/s |
| Esmeralda | 10/s |
| Criativo | 10/s |
