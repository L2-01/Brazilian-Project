# UFO Future

**UFO Future** expande o Applied Energistics 2 da síntese avançada de matéria a
fábricas quânticas paralelas, armazenamento astronômico e simulação estelar.

![UFO Future](../pic/logo.png)

Este guia descreve o comportamento implementado pela build 1.21.1 atual. Use
o JEI para receitas exatas específicas do pacote; datapacks e a configuração do servidor podem
mudar custos enquanto o fluxo de trabalho das máquinas permanece o mesmo.

## Progressão em Resumo

1. Estabeleça uma rede AE2 energizada e produza os primeiros componentes do DMA.
2. Use o <ItemLink id="ufo:dimensional_matter_assembler" /> para receitas
   flexíveis de itens/fluidos, catalisadores e matéria estelar inicial.
3. Construa a linha de multiblocos universais e conecte uma
   <ItemLink id="ufo:quantum_pattern_hatch" /> para padrões de processamento AE2.
4. Melhore os Geradores de Campo Estelar do MK1 ao MK3 para desbloquear receitas e
   acelerar o trabalho de tiers mais baixos.
5. Expanda as CPUs de fabricação e o armazenamento para requisições extremas.
6. Construa o <ItemLink id="ufo:stellar_nexus_controller" /> para simulações
   de tier final e produção de ciclo longo.

> A aposentada Entropic Assembler Matrix foi substituída pelo Nexus de
> Computação Quântica, pela Matriz de Fabricação de Padrões Quântica e pela pipeline de
> autofabricação da Singularidade de Fabricação Infinita.
