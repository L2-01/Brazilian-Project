# UFO Future

**UFO Future** estende o Applied Energistics 2 da síntese avançada de matéria até
fábricas quânticas paralelas, armazenamento astronômico e simulação estelar.

![UFO Future](../pic/logo.png)

Este guia descreve o comportamento implementado pela build 1.21.1 atual. Use o
JEI para as receitas exatas do pacote; datapacks e configuração do servidor podem
mudar custos enquanto o fluxo de trabalho das máquinas permanece o mesmo.

## Progressão em Resumo

1. Estabeleça uma rede AE2 energizada e produza os primeiros componentes do DMA.
2. Use o <ItemLink id="ufo:dimensional_matter_assembler" /> para receitas
   flexíveis de itens/fluidos, catalisadores e matéria estelar inicial.
3. Construa a linha de multiblocos universais e conecte uma
   <ItemLink id="ufo:quantum_pattern_hatch" /> para padrões de processamento AE2.
4. Melhore os Geradores de Campo Estelar de MK1 a MK3 para desbloquear receitas e
   acelerar trabalhos de tier inferior.
5. Expanda CPUs de fabricação e armazenamento para pedidos extremos.
6. Construa o <ItemLink id="ufo:stellar_nexus_controller" /> para simulações
   de tier final e produção de ciclos longos.

> A aposentada Matriz de Montagem Entrópica foi substituída pelo pipeline de
> fabricação automática do Nexus de Computação Quântica, da Matriz de Fabricação
> de Padrões Quântica e da Singularidade de Fabricação Infinita.
