O **Gerador Pegajoso** queima Bolas de Slime e Leite para produzir FE.

## Configuração

O Gerador Pegajoso usa o tipo de receita `excessive_utilities:item_and_fluid_fuel`. Use isto como exemplo:

```json
{
  "type": "excessive_utilities:item_and_fluid_fuel",
  "duration": 100,
  "fe_per_tick": 10,
  "fluid_ingredient": {
    "amount": 250,
    "tag": "c:milk"
  },
  "generator_type": "slimy",
  "item_ingredient": {
    "tag": "c:slime_balls"
  }
}
```
