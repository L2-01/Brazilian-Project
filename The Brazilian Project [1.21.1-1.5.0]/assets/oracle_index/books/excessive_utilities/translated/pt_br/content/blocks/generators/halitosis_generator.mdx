O **Gerador de Halitose** queima Bafo de Dragão para produzir FE.

## Configuração

O Gerador de Halitose usa o tipo de receita `excessive_utilities:single_item_fuel`. Use isto como exemplo:

```json
{
  "type": "excessive_utilities:single_item_fuel",
  "duration": 12000,
  "fe_per_tick": 40,
  "generator_type": "halitosis",
  "ingredient": {
    "item": "minecraft:dragon_breath"
  }
}
```
