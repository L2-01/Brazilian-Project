**Tubos de Transferência** são usados para conectar [Nós de Transferência](@excessive_utilities:transfer_nodes) a destinos, permitindo que eles transfiram itens. O mesmo vale para fluidos e energia, assim como para [Nós de Recuperação](@excessive_utilities:retrieval_node) de todos os tipos.

Usar uma Chave-Inglesa de Tubo numa conexão permite bloqueá-la, impedindo que Nós de Transferência transfiram através dela.
