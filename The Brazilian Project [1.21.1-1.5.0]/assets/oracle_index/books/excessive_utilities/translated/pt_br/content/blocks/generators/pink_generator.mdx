O **Gerador Rosa** queima certos itens rosa para produzir FE.

## Configuração

O Gerador Rosa usa o tipo de receita `excessive_utilities:single_item_fuel`. Use isto como exemplo:

```json
{
  "type": "excessive_utilities:single_item_fuel",
  "duration": 10,
  "fe_per_tick": 40,
  "generator_type": "pink",
  "ingredient": {
    "tag": "c:dyes/pink"
  }
}
```
