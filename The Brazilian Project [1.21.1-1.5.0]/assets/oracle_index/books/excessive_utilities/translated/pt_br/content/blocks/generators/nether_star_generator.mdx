O **Gerador de Estrela do Nether** queima certos itens do tema da estrela do nether para produzir FE.

## Configuração

O Gerador de Estrela do Nether usa o tipo de receita `excessive_utilities:single_item_fuel`. Use isto como exemplo:

```json
{
  "type": "excessive_utilities:single_item_fuel",
  "duration": 2400,
  "fe_per_tick": 4000,
  "generator_type": "nether_star",
  "ingredient": {
    "item": "minecraft:nether_star"
  }
}
```
