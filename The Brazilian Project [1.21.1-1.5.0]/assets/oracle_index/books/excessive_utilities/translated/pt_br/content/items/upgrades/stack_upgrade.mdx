**Melhorias de Agrupamento** podem ser colocadas dentro de [Nós de Transferência e Recuperação](@excessive_utilities:transfer_nodes) para fazê-los mover uma pilha inteira de uma vez, em vez de apenas um item.

Para Nós de Transferência de Fluidos, isso significa mover 1.000 mB de cada vez em vez de 200.
