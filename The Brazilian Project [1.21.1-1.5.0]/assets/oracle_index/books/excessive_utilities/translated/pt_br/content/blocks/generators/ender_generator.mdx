O **Gerador Ender** queima certos itens do tema do End para produzir FE.

## Configuração

O Gerador Ender usa o tipo de receita `excessive_utilities:single_item_fuel`. Use isto como exemplo:

```json
{
  "type": "excessive_utilities:single_item_fuel",
  "duration": 1600,
  "fe_per_tick": 40,
  "generator_type": "ender",
  "ingredient": {
    "tag": "c:ender_pearls"
  }
}
```
