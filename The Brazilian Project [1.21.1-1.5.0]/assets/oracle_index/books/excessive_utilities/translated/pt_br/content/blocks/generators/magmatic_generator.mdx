O **Gerador Magmático** queima Lava para produzir FE.

## Configuração

O Gerador Magmático usa o tipo de receita `excessive_utilities:fluid_fuel`. Use isto como exemplo:

```json
{
  "type": "excessive_utilities:fluid_fuel",
  "duration": 200,
  "fe_per_tick": 1600,
  "generator_type": "magmatic",
  "fluid_ingredient": {
	"amount": 1000,
	"tag": "c:lava"
  }
}
```
