O **Gerador de Redstone Aquecida** queima Lava e Redstone juntos para produzir FE.

## Configuração

O Gerador de Redstone Aquecida usa o tipo de receita `excessive_utilities:magmatic_fuel`. Use isto como exemplo:

```json
{
{
  "type": "excessive_utilities:magmatic_fuel",
  "duration": 1,
  "fe_per_tick": 100,
  "ingredient": {
    "amount": 1,
    "tag": "c:lava"
  }
}
```
