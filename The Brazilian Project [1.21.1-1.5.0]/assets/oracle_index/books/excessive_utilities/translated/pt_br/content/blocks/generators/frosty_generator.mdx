O **Gerador Congelante** queima certos itens gelados para produzir FE.

## Configuração

O Gerador Congelante usa o tipo de receita `excessive_utilities:single_item_fuel`. Use isto como exemplo:

```json
{
  "type": "excessive_utilities:single_item_fuel",
  "duration": 40,
  "fe_per_tick": 40,
  "generator_type": "frosty",
  "ingredient": {
    "item": "minecraft:ice"
  }
}
```
