O **Filtro de Fluidos** é usado para filtrar quais fluidos são permitidos em certas coisas, como [Nós de Transferência de Fluidos](@excessive_utilities:transfer_nodes).

Abrir o Filtro permite inserir até 16 itens portadores de fluido. Por padrão, esses são os fluidos que passarão pelo filtro. Colocar outro Filtro de Fluidos dentro o aninha, permitindo combinar vários Filtros num único item!

Há três botões na parte inferior:

- Inverter
- Usar Tags
- Ignorar Todos os Componentes
