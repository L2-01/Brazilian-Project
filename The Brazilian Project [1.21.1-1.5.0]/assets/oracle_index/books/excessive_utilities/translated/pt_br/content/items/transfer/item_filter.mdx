O **Filtro de Itens** é usado para filtrar quais itens são permitidos em certas coisas, como [Nós de Transferência](@excessive_utilities:transfer_nodes).

Abrir o Filtro permite inserir até 16 itens. Por padrão, esses são os itens que passarão pelo filtro. Colocar outro Filtro de Itens dentro o aninha, permitindo combinar vários Filtros num único item!

Há quatro botões na parte inferior:

- Inverter
- Usar Tags
- Ignorar Dano
- Ignorar Todos os Componentes
