**Vidro Etéreo (Invertido)** é um bloco de vidro.

Criaturas e outras entidades que não são jogadores podem atravessar este bloco. Jogadores que não estão agachados não podem atravessá-lo, mas agachar-se permite a passagem.

Este bloco suporta texturas conectadas quando o [Athena](https://www.curseforge.com/minecraft/mc-mods/athena) está instalado. O Athena também está disponível no [Modrinth](https://modrinth.com/mod/athena-ctm).
