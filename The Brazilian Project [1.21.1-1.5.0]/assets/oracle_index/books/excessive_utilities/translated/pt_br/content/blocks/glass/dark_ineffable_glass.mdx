**Vidro Inefável (Escuro)** é um bloco de vidro.

Jogadores que não estão agachados podem atravessar este bloco, enquanto criaturas não podem. Agachar-se torna o bloco sólido para o jogador. Ele também impede a passagem de luz.

Este bloco suporta texturas conectadas quando o [Athena](https://www.curseforge.com/minecraft/mc-mods/athena) está instalado. O Athena também está disponível no [Modrinth](https://modrinth.com/mod/athena-ctm).
