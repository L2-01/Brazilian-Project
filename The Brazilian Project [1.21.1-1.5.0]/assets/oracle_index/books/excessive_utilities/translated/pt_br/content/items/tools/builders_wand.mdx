A **Varinha do Construtor** permite colocar vários blocos de uma vez.

Usá-la num bloco colocará mais daquele bloco no bloco em que você clicou, incluindo em blocos adjacentes. Naturalmente, isso os consome do seu inventário.

Enquanto segura a Varinha do Construtor, ela renderiza uma estrutura de arame em todos os locais onde os blocos serão colocados.

Ela pode colocar até 9 blocos de uma vez, com base nos blocos mais próximos daquele para o qual você está olhando.

## Configuração

A quantidade máxima de blocos é definida pelo Componente de Dados `excessive_utilities:amount_blocks` do item, em vez de uma opção de configuração.

Por exemplo, `/give @s excessive_utilities:builders_wand[excessive_utilities:amount_blocks=9999]` daria a você uma Varinha do Construtor capaz de colocar até 9999 blocos de uma vez.
