A **Bolsa Espaçosa** é um inventário portátil que armazena o equivalente a um baú duplo. Basta clicar com o botão direito para abrir o inventário da bolsa.

Cada Bolsa tem um UUID, que é um ponteiro para o inventário da Bolsa. Se você perder a Bolsa, pode simplesmente gerar uma nova com o mesmo UUID, se necessário.
