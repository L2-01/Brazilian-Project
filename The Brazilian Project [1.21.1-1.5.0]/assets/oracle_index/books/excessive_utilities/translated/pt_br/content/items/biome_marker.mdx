**Marcadores de Bioma** são usados para marcar um bioma, seja para uso com o [Terraformador](@excessive_utilities:terraformer) ou com a [Escavadeira Quântica](@excessive_utilities:quantum_quarry).

Use o Marcador de Bioma num bloco para salvar o bioma daquela localização no item.
