**Lírios Ender** são uma flor especial que pode ser encontrada nas ilhas externas do End.

Elas crescem em 7 estágios. Na idade máxima, podem ser interagidas para derrubar uma Pérola do Ender.

Os Lírios Ender, assim como os Endermen, odeiam água. Se se molharem, eles se teleportam para longe. Isso inclui o [Regador](@excessive_utilities:watering_can), mas *não* o [Regador Reforçado](@excessive_utilities:reinforced_watering_can).
