**Tambores** armazenam uma grande quantidade de um único fluido e mantêm seu conteúdo quando quebrados.

Suas capacidades padrão são:

| Nível | Capacidade (mB) |
| ---- | ------------- |
| Pedra | 16.000 |
| Ferro | 256.000 |
| Grande Reforçado | 4.096.000 |
| Demoniacamente Gigantesco | 65.536.000 |
| Bedrônio | 1.048.576.000 |
| Criativo | MAX_INT |

## Configuração

As capacidades de cada nível podem ser configuradas.
