A **Mesa Pacífica** ocasionalmente simula a morte de um monstro, inserindo os itens largados num inventário adjacente. Ela só funciona no modo Pacífico, e o inventário deve conter uma Espada.

Encantamentos na Espada afetam os itens largados, e a Espada é danificada como se tivesse sido usada para matar a criatura.

## Configuração

A frequência com que a Mesa Pacífica simula uma morte, assim como se ela funciona no modo Pacífico, pode ser configurada.
