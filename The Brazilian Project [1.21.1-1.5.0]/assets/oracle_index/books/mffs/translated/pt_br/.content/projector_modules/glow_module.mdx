# Módulo de Brilho

O Módulo de Brilho pode ser usado num [](@mffs:projector) para iluminar a área ao redor do campo.

Instalar Módulos de Brilho num Projetor faz o campo de força emitir luz. Conforme mais Módulos de Brilho são adicionados
(até um máximo de 64), o brilho do campo aumenta — até ficar igual ao da Pedra Luminosa.
