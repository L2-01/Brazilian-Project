# Módulo Antipessoal

O Módulo Antipessoal é um módulo opcional para a [](@mffs:interdiction_matrix).

<PrefabObtaining />

## Efeito

Com este módulo instalado, a Matriz detecta automaticamente jogadores não autorizados que entram no seu alcance de ação e
os mata — quase instantaneamente.

Criaturas pacíficas e hostis não são prejudicadas.
