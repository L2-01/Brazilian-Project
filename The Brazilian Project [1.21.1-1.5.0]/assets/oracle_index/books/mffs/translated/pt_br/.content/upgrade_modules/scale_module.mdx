# Módulo de Escala

O Módulo de Escala pode ser colocado nos espaços de melhoria de várias máquinas do MFFS para aprimorar suas capacidades de distância.

Seus efeitos variam conforme a máquina, mas geralmente incluem:
- Aumentar o tamanho do campo de força
- Aumentar a área de interdição
- Aumentar o impulso de combustível num [](@mffs:coercion_deriver)
