# Módulo de Desintegração

O Módulo de Desintegração pode ser usado num [](@mffs:projector) para alterar o efeito que um campo de força exerce sobre o seu
entorno. Colocar um Módulo de Desintegração nos espaços de matriz de um Projetor faz o campo gerado
quebrar qualquer bloco que esteja obstruindo-o. Os blocos quebrados caem como itens e podem ser recolhidos.

<PrefabObtaining />

## Uso

O Módulo de Desintegração é compatível com todos os modos de projetor e pode ser usado para inverter o efeito do
[](mffs:stabilization_module).
Adicionar [Módulos de Velocidade](@mffs:speed_module) a um Projetor permite desintegrar vários blocos de uma vez.
Ele também pode ser combinado com um [](@mffs:collection_module) para recolher automaticamente os blocos quebrados.
