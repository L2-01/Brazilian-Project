# Cartão de Identificação

Os Cartões de Identificação do MFFS são usados em conjunto com o [](@mffs:biometric_identifier) para gerenciar os direitos e
privilégios dos jogadores.

<PrefabObtaining />

## Uso

Antes de ser usado, um Cartão de Identificação precisa ser atribuído a um jogador. Um Cartão de Identificação pode ser atribuído
a você mesmo clicando com o botão direito agachado enquanto o segura. Você também pode clicar com o botão direito agachado em outros jogadores para atribuir o
cartão a eles. Ative o cartão de novo para limpar a identidade armazenada.
