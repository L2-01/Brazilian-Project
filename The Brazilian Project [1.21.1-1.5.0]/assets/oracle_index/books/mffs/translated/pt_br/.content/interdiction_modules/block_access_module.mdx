# Módulo de Acesso a Blocos

O Módulo de Acesso a Blocos é um módulo opcional para a [](@mffs:interdiction_matrix).
Ele permite à Matriz inibir a capacidade do jogador de clicar com o botão direito num bloco e acessar sua tela de GUI.

<PrefabObtaining />

## Efeito

Se um jogador não autorizado tentar clicar com o botão direito num bloco ou máquina localizado dentro do alcance de ação de uma Matriz de
Interdição (equipada com o Módulo de Acesso a Blocos), ele não poderá abrir a GUI. Como seria de se esperar, blocos
ou máquinas fora da área de ação podem ser usados normalmente.
