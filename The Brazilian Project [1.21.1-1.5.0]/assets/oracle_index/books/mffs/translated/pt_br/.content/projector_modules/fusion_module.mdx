# Módulo de Fusão de Campos

O Módulo de Fusão de Campos pode ser colocado nos espaços de matriz de um [](@mffs:projector) para fundir dois ou mais campos projetados.

O módulo corta quaisquer blocos projetados que se sobreponham a outro campo de força. Vários campos de força com esse
módulo são então fundidos em um só, sem emendas.
