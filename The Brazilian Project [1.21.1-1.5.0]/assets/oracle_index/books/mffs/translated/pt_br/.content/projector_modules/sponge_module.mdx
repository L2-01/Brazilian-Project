# Módulo de Esponja

Colocar um Módulo de Esponja num [](@mffs:projector) faz com que ele detecte e remova continuamente quaisquer fluidos contidos dentro
do campo. A velocidade com que os fluidos são removidos pode ser aumentada instalando [Módulos de Velocidade](@mffs:speed_module).
Taxas maiores podem ser necessárias para remover fluidos infinitos, como [Água](@mffs:water).
