# Módulo Antigeração

O Módulo Antigeração é um módulo opcional para a [](@mffs:interdiction_matrix).

<PrefabObtaining />

## Efeito

Com este módulo instalado, a Matriz impede que entidades hostis ou pacíficas sejam geradas dentro da sua área de ação.

Se um jogador tiver um ovo gerador, ficar parado logo fora do alcance de ação da Matriz permite gerar a entidade
dentro da região protegida.
