# Módulo Antiamistoso

O Módulo Antiamistoso é um módulo opcional para a [](@mffs:interdiction_matrix).

<PrefabObtaining />

## Efeito

Com este módulo instalado, a Matriz detecta automaticamente entidades pacíficas (como ovelhas, vacas e aldeões) que
entram no seu alcance de varredura e as mata — quase instantaneamente. Jogadores e criaturas hostis saem ilesos.
