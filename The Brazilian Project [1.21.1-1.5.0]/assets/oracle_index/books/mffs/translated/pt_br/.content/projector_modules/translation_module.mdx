# Módulo de Translação

O Módulo de Translação pode ser colocado nos espaços de campo do [](@mffs:projector) para deslocar a posição do campo projetado.

Você pode mover o campo de força em cada direção colocando Módulos de Translação no espaço de campo correspondente àquele
lado. Cada módulo move o campo em 1 bloco.
