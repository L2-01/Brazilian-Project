# Cartão de Frequência

O Cartão de Frequência pode guardar, memorizar e gerar frequências para interagir com máquinas. Sua frequência pode ser definida
colocando-o no espaço de frequência de uma máquina. Usá-lo em qualquer máquina define a frequência dessa máquina para
a que estiver no cartão. Você pode gerar uma frequência aleatória clicando com o botão direito agachado enquanto segura o cartão.
