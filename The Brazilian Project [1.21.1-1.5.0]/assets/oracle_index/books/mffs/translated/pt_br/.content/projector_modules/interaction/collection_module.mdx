# Módulo de Coleta

Quando colocado nos espaços de matriz de um [Projetor](@mffs:projector), em combinação com um [](@mffs:disintegration_module),
o Módulo de Coleta recolhe para inventários ao redor do Projetor os itens largados pelos blocos destruídos.
