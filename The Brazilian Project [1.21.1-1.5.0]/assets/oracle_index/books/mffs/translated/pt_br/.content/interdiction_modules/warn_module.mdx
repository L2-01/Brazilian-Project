# Módulo de Aviso

O Módulo de Aviso é um módulo opcional para a [](@mffs:interdiction_matrix).

<PrefabObtaining />

## Efeito

O Módulo de Aviso pode ser colocado nos espaços de matriz de uma Matriz de Interdição para enviar periodicamente um aviso a todos os
jogadores não autorizados dentro do seu Alcance de Ação.
