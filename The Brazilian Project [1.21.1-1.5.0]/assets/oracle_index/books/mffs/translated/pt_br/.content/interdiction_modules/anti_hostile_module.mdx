# Módulo Antihostil

O Módulo Antihostil é um módulo opcional para a [](@mffs:interdiction_matrix).

<PrefabObtaining />

## Efeito

Com este módulo instalado, a Matriz consegue detectar automaticamente criaturas hostis que entram no seu alcance de varredura e
matá-las — quase instantaneamente.

Jogadores e entidades não hostis, como aldeões e animais, não são prejudicados.
