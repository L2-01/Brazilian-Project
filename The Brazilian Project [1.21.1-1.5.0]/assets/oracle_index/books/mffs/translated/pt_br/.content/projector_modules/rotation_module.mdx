# Módulo de Rotação

O Módulo de Rotação pode ser colocado nos espaços de campo do [](@mffs:projector) para girar o campo projetado.

Você pode mover o campo de força ao redor do eixo x, y ou z colocando Módulos de Rotação no espaço correspondente àquele eixo.

- LESTE, OESTE — Ajustam a guinada (Yaw)
- CIMA, BAIXO — Ajustam a inclinação (Pitch)
- SUL, NORTE — Ajustam a rolagem (Roll)
