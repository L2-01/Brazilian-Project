# Teletransportação de Flu

A **Teletransportação de Flu** é uma mecânica que permite teleportar-se entre certas estruturas chamadas Lareiras de Flu.

## Lareiras de Flu

Faça uma Lareira de Flu colocando Tijolos no mundo e usando uma Placa de Flu neles. Todos eles serão convertidos em Tijolos de Pó de Flu que fazem parte da Lareira.

Lareiras de Flu podem ter um nome, que é como você se teleporta até ela. Renomeie a Placa numa Bigorna, e a Lareira que ela cria terá esse nome.

Lareiras de Flu não *precisam* ter um nome, mas se não tiverem, você não poderá se teleportar até ela. Você ainda conseguirá se teleportar *a partir* dela, no entanto!

## Usando

Fique sobre uma Lareira de Flu e diga o nome de outra. Se você tiver [Pó de Flu](@irregular_implements:floo_powder) na mão, ou uma [Bolsa de Pó de Flu](@irregular_implements:floo_pouch) não vazia em qualquer lugar do seu inventário, você será teleportado para a Lareira cujo nome você disse.

Você só pode se teleportar para Lareiras que estejam na mesma dimensão que você.

Você não precisa acertar o nome 100%! Desde que chegue perto o suficiente, funcionará.

Se você não tiver acesso a uma Lareira de Flu para se teleportar, pode usar um [Símbolo de Flu](@irregular_implements:floo_token) no lugar!
