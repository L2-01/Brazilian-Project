O **Radar de Bioma** é uma estrutura multibloco que ajuda você a encontrar biomas no mundo.

Primeiro, você precisa construir a estrutura:

![](@irregular_implements:structures/biome_radar)

Depois, insira um **Cristal de Bioma**. Existe um para cada Bioma do jogo, e eles podem ser encontrados em praticamente qualquer baú com saque.

Se o bioma existir no mundo, os fogos no topo das Barras de Ferro começarão a soprar na direção dele. Se isso não bastar, você pode usar um [Filtro de Localização](@irregular_implements:location_filter) nele para defini-lo à posição do bioma.

Com isso, você pode combiná-lo com uma [Bússola de Ouro](@irregular_implements:golden_compass) para chegar lá!
