A **Interface do Jogador** permite interagir com o inventário do dono por meio de canos e similares.

Cada face aponta para uma parte diferente do inventário:
- Cima: armadura
- Baixo: barra de atalhos
- Norte: mão secundária
- Outros: inventário principal
