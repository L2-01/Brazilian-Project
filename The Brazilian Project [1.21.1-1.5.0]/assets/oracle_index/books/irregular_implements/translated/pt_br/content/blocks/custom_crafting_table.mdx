A **Bancada de Trabalho Personalizada** é funcionalmente idêntica a uma Bancada de Trabalho comum, mas tem a aparência do bloco com o qual foi criada.

Por exemplo, 8 Troncos de Carvalho ao redor de uma Bancada de Trabalho produzem uma Bancada de Trabalho com aparência de Tronco de Carvalho.
