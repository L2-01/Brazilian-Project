A **Tintura de Super Lubrificante** pode ser combinada com qualquer item de bota para fazê-lo anular completamente o atrito quando usado, enquanto abaixo de uma certa velocidade.

Você pode combinar as botas lubrificadas com uma Garrafa de Água para lavá-las do lubrificante.
