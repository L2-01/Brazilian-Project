O **Filtro de Item** tem uma lista de até 9 itens, e pode servir tanto como Lista de Permissões quanto como Lista de Bloqueios. Alterne isso pelo botão na extremidade direita da GUI.

Acima de cada espaço preenchido há dois botões.

O botão da esquerda permite alternar se o espaço é um Filtro de Item ou um Filtro de Tag. Por exemplo, colocar um Graveto no espaço fará, por padrão, com que ele filtre pelo item `minecraft:stick`. Mudá-lo para Filtro de Tag fará com que ele filtre por uma das tags de item do Graveto.

A função do botão da direita muda dependendo de o espaço ser um Filtro de Item ou um Filtro de Tag.

Para espaços de Filtro de Item, ele alterna se o item deve ou não corresponder aos componentes de dados (como encantamentos, nomes personalizados etc.) do item no espaço.

Para espaços de Filtro de Tag, ele alterna por qual das tags do item filtrar.
