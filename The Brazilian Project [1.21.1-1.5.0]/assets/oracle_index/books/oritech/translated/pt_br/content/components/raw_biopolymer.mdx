Um precursor orgânico de plásticos industriais, feito de matéria biológica.

**Fabricação**
- **Centrífuga**: extraído de [Trigo Embalado](@oritech:packed_wheat), [Biocombustível Sólido](@oritech:solid_biofuel)
ou Blocos de Biomassa usando Água.

**Uso**
Usado como base para plásticos, fluidos especializados e aumentos biológicos.
