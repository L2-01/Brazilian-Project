Queima combustíveis comuns de fornalha (carvão, madeira, carvão vegetal, etc.) para gerar energia.
Este é o seu gerador inicial para as necessidades de energia do início de jogo.

## Uso

Insira qualquer combustível queimável no inventário.
O gerador o queima e armazena energia no seu buffer interno,
que é enviada às máquinas ou cabos conectados.

O gerador básico não aceita complementos. Por padrão, gera 64 RF/t.

É uma boa máquina para a sua primeira oficina porque é barato, aceita vários combustíveis e não exige montagem multibloco.
Um gerador basta para uma linha inicial, mas construir um segundo ou terceiro costuma ser a forma mais fácil de alimentar
uma [Montadora](@oritech:assembler_block), um [Pulverizador](@oritech:pulverizer_block)
e uma [Fornalha Elétrica](@oritech:powered_furnace_block) ao mesmo tempo.
