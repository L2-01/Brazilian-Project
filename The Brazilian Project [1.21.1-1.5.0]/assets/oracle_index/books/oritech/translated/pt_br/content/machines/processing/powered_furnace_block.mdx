A Fornalha Elétrica é uma substituta moderna da
fornalha de pedra tradicional. Ela usa energia RF para fundir itens com velocidade
e eficiência muito maiores. A fornalha elétrica é duas vezes mais rápida que uma fornalha normal.


Esta é uma das melhores primeiras máquinas de qualidade de vida para construir depois do seu primeiro gerador, pois elimina totalmente a necessidade
de combustível manual para fundição.
