Queima combustíveis líquidos como petróleo ou diesel para produzir grandes quantidades de energia. A taxa de geração padrão é de 512 RF/t.

<Callout variant="warning">
    A energia só sai pelos 2 pontos de conexão amarelos na frente da máquina.

</Callout>

Aceita combustíveis líquidos por tubos ou baldes.
Este é um multibloco que precisa de [núcleos de máquina]($multiblocks). Você também pode inserir ou extrair combustível clicando
na máquina com um item que contenha fluido.

Petróleo cru já é suficiente para fazê-lo funcionar, mas combustíveis refinados são onde a máquina se torna realmente eficiente. Se você já tiver uma refinaria, este costuma ser o melhor primeiro consumidor para esses combustíveis melhorados.

<Callout variant="info">
    Combustíveis refinados fornecem uma densidade de energia muito maior que recursos brutos.
</Callout>
