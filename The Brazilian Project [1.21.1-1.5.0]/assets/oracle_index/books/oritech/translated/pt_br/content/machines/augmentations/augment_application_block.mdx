pesquisar e instalar melhorias permanentes no seu corpo.
Essas aumentações fornecem vários benefícios, indo de aumentos passivos
de atributos a habilidades totalmente novas.

# Pesquisa e Desenvolvimento

Para começar, entre no **Centro de Aumentação Cibernética** montado.
Isso abre a interface de pesquisa, onde você pode navegar e iniciar projetos.
Cada aumentação exige energia e recursos específicos, retirados do seu inventário pessoal ou
do armazenamento interno da máquina (acessível pela interface).

Muitas melhorias de alto nível exigem pesquisas anteriores, como mostrado na árvore tecnológica.

O centro funciona como um hub para **Estações de Pesquisa**, construídas como complementos multibloco. A unidade principal suporta
até **três estações**, permitindo processamento paralelo.
*   Cada estação exige **3 Núcleos de Máquina**.
*   Uma estação executa uma tarefa de pesquisa ativa por vez.

# Aplicação e Controle

Uma vez concluída a pesquisa, a aumentação fica disponível para instalação. O procedimento exige um custo único de recursos
para fundir permanentemente a tecnologia ao seu jogador.

Se você tiver aumentações instaladas, pode carregá-las na máquina usando a função
**Importar** (botão inferior esquerdo da UI).

**Gerenciamento de Aumentações**:
Suas melhorias foram feitas para ser permanentes: elas não exigem manutenção nem custo contínuo de energia.
Porém, se alguma habilidade se mostrar uma distração (como a **Visão de Minérios** ou a **Hipervelocidade**), ela pode ser ativada e desativada à vontade.

*   **Menu de Alternância**: segure a tecla de aumentações (**[G]** por padrão) para abrir a interface radial. Passe o cursor sobre o
aumento desejado e solte para alternar seu estado.
*   **Remoção**: embora as aumentações sejam feitas para ser permanentes, elas podem ser removidas se necessário.
Note que os recursos investidos na instalação não são reembolsáveis.

**Informações para Desenvolvedores de Modpacks**

As aumentações do Oritech são totalmente orientadas por dados e configuráveis, permitindo ampla personalização via datapacks.

*   **Aumentos Modificadores**: alteram atributos de entidades (ex.: velocidade, alcance, vida).
*   **Aumentos de Efeito**: aplicam efeitos de status semelhantes a poções.
*   **Aumentos Personalizados**: implementam lógica única (ex.: Visão de Minérios). Eles podem ser referenciados em datapacks, mas exigem um mod
Java para a lógica subjacente.

Aumentos existentes podem ser modificados ou desativados, e novos podem ser definidos via JSON.
*   **Exemplo de Definição**: [Aumento de Dano de Ataque (GitHub)](https://github.com/Rearth/Oritech/blob/1.21/fabric/src/main/generated/data/oritech/recipe/augment/attackdamage.json)
*   **Local das Texturas**: `oritech/textures/gui/augment`

Lembre-se de incluir entradas de tradução para qualquer adição personalizada.
