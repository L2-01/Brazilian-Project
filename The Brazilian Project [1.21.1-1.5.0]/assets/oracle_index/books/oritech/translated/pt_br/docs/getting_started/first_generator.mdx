Ele queima combustíveis normais de fornalha e gera **64 RF/t**, o suficiente para colocar suas primeiras máquinas de processamento para funcionar.

Um gerador é suficiente para uma oficina inicial, mas você vai superá-lo rapidamente. Não tenha medo de construir mais de um enquanto trabalha em direção a geradores melhores e automação.

Quando ele estiver funcionando, uma [Fornalha Elétrica](@oritech:powered_furnace_block) costuma ser uma boa primeira melhoria de conveniência.
