A fabricação manual é aceitável para as primeiras máquinas. Assim que possível, porém, mova a produção de ligas para uma configuração de [Pulverizador](@oritech:pulverizer_block) mais [Fundição](@oritech:foundry_block).

Essa mudança é uma das maiores melhorias de eficiência na progressão inicial do Oritech, e também te prepara para ligas posteriores como bioaço, energita e durácio.
