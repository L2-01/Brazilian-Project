# O mod adiciona todos os recursos de qualidade de vida listados abaixo
## Multiplicação de Padrões nos Provedores de Padrões: Isso adiciona um botão ao Provedor de Padrões que permite multiplicar ou dividir todos os Padrões contidos
__Os multiplicadores se acumulam!__

![modify_patterns.png](assets/modify_patterns.png)
## Modos de bloqueio extras: Isso adiciona dois modos de bloqueio extras a todos os Provedores de Padrões
### Padrão: Este é o modo de bloqueio padrão do ae2, ele enviará o padrão se o armazenamento conectado não contiver nenhuma das entradas do padrão neste Provedor de Padrões; se o armazenamento contiver qualquer coisa que não seja uma entrada de padrão, o modo de bloqueio o ignorará e ainda assim enviará o padrão.

![blocking_1.png](assets/blocking/blocking_1.png)

### Completo: Este modo de bloqueio não enviará o padrão se o armazenamento conectado contiver qualquer coisa.

![blocking_2.png](assets/blocking/blocking_2.png)

### Inteligente: Permite que o Provedor de Padrões envie o mesmo padrão se o armazenamento alvo contiver apenas as entradas desse padrão específico

![blocking_3.png](assets/blocking/blocking_3.png)
