# O mod adiciona todos os recursos de QoL listados abaixo
## Multiplicação de Padrões em Provedores de Padrões: adiciona um botão ao Provedor de Padrões que permite multiplicar ou dividir todos os Padrões contidos
__Os multiplicadores se acumulam!__

![modify_patterns.png](assets/modify_patterns.png)
## Modos de bloqueio extras: adiciona dois modos de bloqueio extras a todos os Provedores de Padrões
### Padrão: este é o modo de bloqueio padrão do AE2; ele empurrará o padrão se o armazenamento conectado não contiver nenhuma das entradas do padrão neste Provedor de Padrões; se o armazenamento contiver algo que não seja uma entrada de padrão, o modo de bloqueio o ignorará e ainda empurrará o padrão.

![blocking_1.png](assets/blocking/blocking_1.png)

### Cheio: este modo de bloqueio não empurrará o padrão se o armazenamento conectado contiver qualquer coisa.

![blocking_2.png](assets/blocking/blocking_2.png)

### Inteligente: permite ao Provedor de Padrões empurrar o mesmo padrão se o armazenamento alvo contiver apenas as entradas deste padrão específico

![blocking_3.png](assets/blocking/blocking_3.png)
