## Atualmente, o mod só adiciona os dois cartões de melhoria listados abaixo
- Cartão de Auto Preenchimento: Este cartão é uma melhoria para Provedores de Padrões, ele cancela automaticamente a fabricação assim que
envia o padrão. _Nota: Não funciona bem com padrões de fabricação, então tenha cuidado_
<ItemImage id="auto_complete_card" />
- Cartão de Reabastecimento de Padrões: Este cartão é uma melhoria para o <ItemLink id="wireless_exp_encoding_terminal" />
e o <ItemLink id="ae2wtlib:wireless_universal_terminal" /> que reabastece automaticamente o espaço de padrão em branco no
Terminal de Codificação de Padrões Expandido

_Nota: O cartão só tenta reabastecer os padrões cada vez que o botão de codificar é clicado, esta foi a solução mais eficiente em recursos_
<ItemImage id="pattern_refiller_card" />
