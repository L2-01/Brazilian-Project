# Fornecedor de Padrões Recursivo do AE2

## ✨ Recursos Principais

### 🎯 Geração Automática de Padrões
- **Dependências Inteligentes**: cria automaticamente padrões de ingredientes de fabricação que faltam, em tempo real.
- **Lógica Recursiva**: percorre cadeias de dependência profundas até a profundidade máxima configurada.
- **Descoberta de Receitas**: só monta padrões para itens com receitas válidas e solucionáveis.
- **Suporte Universal**: gera padrões de dependência para todos os componentes de fabricação padrão.
- **Compatível com**: AE2, Extended AE2, Advanced AE e ExtendedAE-Plus!

### ⚙️ Integração Perfeita com a GUI
- **Alternância Direta no Terminal**: ative a recursão diretamente dentro do Terminal de Codificação de Padrões usando um botão dedicado (configurável via `enableEncodingGuiToggle`).
- **Focado em Padrão de Fabricação**: integrado perfeitamente à codificação de Padrões de Fabricação, ficando oculto nos modos que não são de fabricação.
- **Método Alternativo por Receita**: permite converter padrões existentes via receitas de bancada de trabalho (`Padrão + Lingote de Ferro`).

### 🎨 Feedback Visual Limpo
- **Dicas de Ferramenta Nativas**: exibe um sutil rótulo `Recursivo` combinando com o design de dicas de ferramenta nativo do AE2.
- **Marcação Persistente**: recodificar padrões no terminal mantém a marcação recursiva sem passos extras.
