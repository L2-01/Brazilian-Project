# Fornecedor de Padrões Recursivo do AE2

## 💡 Cenário de Exemplo

### Configuração Tradicional do AE2
Para fabricar uma Picareta de Ferro automaticamente, tradicionalmente você precisa codificar e registrar manualmente:
1. Padrão de Picareta de Ferro
2. Padrão de Graveto
3. Padrão de Tábuas de Madeira (a partir de Troncos)
4. Padrão de fundição de Lingote de Ferro (a partir de Ferro Bruto)
5. Preencher manualmente os Provedores de Padrões com cada sub-receita...

### Com o Fornecedor de Padrões Recursivo do AE2
1. Abra o **Terminal de Codificação de Padrões**, ative a alternância de **Padrão Recursivo** e codifique UM padrão de Picareta de Ferro.
2. Insira-o no seu Provedor de Padrões.
3. **Todos os subpadrões necessários são gerados automaticamente!**

O mod percorre a árvore de fabricação inteira até as tábuas, gravetos e peças intermediárias, mantendo sua rede limpa e eliminando a fabricação repetitiva de padrões.
