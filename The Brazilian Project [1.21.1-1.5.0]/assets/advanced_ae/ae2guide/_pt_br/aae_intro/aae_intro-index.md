# Advanced AE!

O Advanced AE foca em melhorar a experiência do usuário ao lidar com seu Sistema ME e em expandir as possibilidades de
sistemas de fim de jogo. Este mod permite melhorar provedores de padrões com a capacidade de enviar itens para lados
específicos das máquinas-alvo e criar computadores multibloco capazes de executar uma quantidade ilimitada de
fabricações, compartilhando co-processadores, enquanto houver armazenamento de fabricação, além de uma porção de outras
melhorias de qualidade de vida!
