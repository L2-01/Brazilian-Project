# Melhorias do Provedor de Padrões Avançado

O AdvancedAE fornece itens que permitem melhorar provedores de padrões sem precisar mover todos os seus padrões e
melhorias.

## Melhoria de Provedor de Padrões Avançado

<ItemImage id="advanced_ae:adv_pattern_provider_upgrade" scale="3"></ItemImage>

Essas melhorias podem ser usadas em Provedores de Padrões AE comuns e em Provedores de Padrões Estendidos do ExtendedAE. Usá-la nessas
máquinas irá melhorá-las para a versão avançada mantendo a mesma quantidade de espaços que tinham antes. Isso
significa que você não perderá os materiais usados para melhorar provedores comuns para provedores estendidos no processo.

## Melhoria de Capacidade do Provedor de Padrões Avançado

<ItemImage id="advanced_ae:adv_pattern_provider_capacity_upgrade" scale="3"></ItemImage>

Melhorias de capacidade são usadas para melhorar Provedores de Padrões comuns diretamente para um Provedor de Padrões Avançado com 36
espaços de padrão.
