# Formador de Feixe (Parte)

<ItemImage id="me_beam_former:beam_former_part" scale="4" />

Uma parte de cabo que forma uma conexão AE2 ponto a ponto usando um feixe.

## Uso

- Coloque-a num cabo AE2.
- Aponte-a para outro Formador de Feixe (Parte) voltado de volta.
- Um bloco sólido bloqueia o feixe.
- Alcance efetivo: até 32 blocos.

## Alternar o feixe

- Agache + clique com o botão direito de mão vazia para ocultar/mostrar o feixe.
