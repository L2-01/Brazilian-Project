# Formador de Feixe ME (Peça)

<ItemImage id="me_beam_former:beam_former_part" scale="4" />

Uma peça de cabo que forma uma conexão AE2 ponto a ponto usando um feixe.

## Uso

- Coloque-a num cabo AE2.
- Aponte-a para outro Formador de Feixe ME (Peça) virado de volta para ela.
- Um bloco sólido bloqueia o feixe.
- Alcance efetivo: até 32 blocos.

## Alternar feixe

- Agachar + clique direito com a mão vazia para ocultar/mostrar o feixe.
