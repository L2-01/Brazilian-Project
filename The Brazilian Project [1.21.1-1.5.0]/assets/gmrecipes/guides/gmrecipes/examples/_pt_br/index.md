# Exemplos de Receitas

Um exemplo funcional de cada tipo de receita que um mod registra, escolhido entre as receitas
realmente carregadas neste mundo. Uma caixa que desenha é um renderizador funcional; um *Couldn't
find a handler for recipe* vermelho indica um tipo que nada ainda cobre.

Nada aqui é escrito à mão, então as páginas acompanham o que um pack mudar. A página de um mod só
aparece quando esse mod está instalado.
