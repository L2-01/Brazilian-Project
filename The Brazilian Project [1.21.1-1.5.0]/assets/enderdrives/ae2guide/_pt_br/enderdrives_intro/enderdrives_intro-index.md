# EnderDrives!

O EnderDrives foca em uma forma diferente de armazenar itens. Esses drives se conectam entre si com base na frequência definida para cada um. Todos os drives com a mesma frequência e privacidade compartilham o mesmo conteúdo, independentemente de quem os fabricou. Seja no seu sistema AE2, em outra dimensão ou no sistema de outro jogador, o conteúdo é sincronizado globalmente.
