# Interações do Terminal

Os terminais exibirão a energia armazenada como este *fluido verde*.

![FE_GUI](../pic/fe_terminal.png)

Ele não é um fluido de verdade, e você não pode usar baldes para enchê-lo.

Você pode usar um recipiente de energia, como baterias ou ferramentas elétricas, para encher/drenar energia de/para ele.

![FE_GUI2](../pic/fe_terminal2.png)
