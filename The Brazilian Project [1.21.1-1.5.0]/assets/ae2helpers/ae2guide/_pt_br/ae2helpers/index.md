**ae2helpers** é um addon de Qualidade de Vida para o Applied Energistics 2, criado para tornar as configurações de autofabricação mais suaves e compactas.

# Recursos

**1. Cartão de Importação de Resultado de Fabricação**
Uma melhoria especializada para o **Provedor de Padrões**.
*   **O que faz:** Permite que um Provedor de Padrões **empurre** ingredientes para uma máquina e **puxe** os resultados prontos de volta usando a mesma face.
*   **Benefício:** Elimina a necessidade de Pontos de Importação separados e canais extras para máquinas de processamento simples.
*   Só é útil/necessário em máquinas que não empurram automaticamente seus resultados para máquinas vizinhas.

**2. Inserção Automática de Receita**
Um fluxo de trabalho aprimorado no **Terminal de Fabricação**.
*   **O que faz:** Quando você solicita uma autofabricação de uma receita no terminal, a grade entra em estado de "espera" com Itens Fantasmas.
*   **Benefício:** No momento em que suas CPUs terminarem o trabalho, os itens são **inseridos automaticamente** na grade. Chega de esperar para clicar na receita de novo!
