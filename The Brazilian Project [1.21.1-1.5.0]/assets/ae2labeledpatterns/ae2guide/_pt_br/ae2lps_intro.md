# AE2 Labeled Patterns
![ícone de título](labeler_titleimg_lit.png)
## Sobre
Um mod simples que adiciona a capacidade de rotular provedores de padrões no Applied Energistics 2, permitindo organizar seus padrões no novo terminal de acesso a padrões.
## Recursos
- Nova ferramenta [rotuladora](labeler.md) para rotular ou renomear qualquer provedor de padrões.
- Novo [terminal de acesso a padrões ME](labeled_pattern_access_terminal.md) que pode exibir padrões rotulados separadamente de acordo com os rótulos.
- Oferece movimentação rápida (Shift+clique) entre os espaços de padrões e o inventário do jogador para padrões codificados no novo terminal de acesso a padrões.
