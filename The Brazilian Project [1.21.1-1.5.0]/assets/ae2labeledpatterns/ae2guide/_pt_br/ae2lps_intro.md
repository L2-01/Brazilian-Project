# AE2 Labeled Patterns
![title icon](labeler_titleimg_lit.png)
## Sobre
Um mod simples que adiciona a capacidade de etiquetar provedores de padrões no Applied Energistics 2, permitindo organizar seus padrões no novo terminal de acesso a padrões.
## Recursos
- Nova ferramenta [etiquetador](labeler.md) para etiquetar ou renomear qualquer provedor de padrões.
- Novo [terminal de acesso a padrões ME](labeled_pattern_access_terminal.md) que pode exibir padrões etiquetados separadamente de acordo com as etiquetas.
- Oferece movimentação rápida (Shift+clique) entre os espaços de padrões e o inventário do jogador para padrões codificados no novo terminal de acesso a padrões.
