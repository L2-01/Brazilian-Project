# Etiquetador
<ItemImage id="ae2labeledpatterns:labeler" scale="4"></ItemImage>
O Etiquetador é uma ferramenta para gerenciar etiquetas e aplicar ou limpar etiquetas em provedores de padrões.

## GUI
Clique com o botão direito no ar para abrir a GUI do etiquetador.

Na GUI, na área central, você verá um campo de entrada para digitar uma etiqueta e um botão para salvá-la. Não se esqueça de salvar a etiqueta depois de editá-la.  
Na barra de ferramentas à esquerda, você pode alternar o modo de bloqueio de entrada para controlar se o campo de entrada fica ativado ou não.  
Você também pode abrir o botão da lista de etiquetas para mostrar todas as etiquetas que este etiquetador salvou.  
Na GUI da lista de etiquetas, você pode selecionar qualquer etiqueta para ser a etiqueta atual e apagar qualquer etiqueta de que não precise mais.

Além disso, você pode ativar ou desativar a função de renomear clicando no botão de renomear.
Quando a função de renomear está ativada, toda operação afetará o nome em vez da etiqueta.
Por exemplo, se você definir a etiqueta como "Máquina" e a função de renomear estiver ativada,
ao aplicar a etiqueta a um provedor de padrões,
ele renomeará o provedor de padrões para "Máquina" em vez de aplicar a etiqueta "Máquina".

## No Jogo
Normalmente, para aplicar uma etiqueta, segure o etiquetador na mão e dê Shift+clique direito num bloco de provedor de padrões;
você receberá uma mensagem no chat confirmando que a etiqueta foi aplicada.
Se estiver usando um mod de tooltip como o Jade,
você poderá ver a informação sobre a etiqueta aplicada no tooltip do bloco do provedor de padrões.

O Etiquetador tem 5 modos, que podem ser alternados segurando **Shift** (padrão; o nome do atalho é "Modificador 1 para itens da roda do mouse") e rolando a roda do mouse para cima ou para baixo.  
Os modos são:
1. **Definir (Único)**: modo padrão; Shift+clique direito num bloco de provedor de padrões para aplicar a etiqueta
2. **Limpar (Único)**: Shift+clique direito num bloco de provedor de padrões para limpar a etiqueta
3. **Definir (Área)**: Shift+clique direito em dois blocos para definir uma área; então todos os blocos na área serão verificados e receberão a etiqueta atual
4. **Limpar (Área)**: Shift+clique direito em dois blocos para definir uma área; então todos os blocos na área serão verificados e limpos
5. **Copiar**: Shift+clique direito num bloco de provedor de padrões para copiar a sua etiqueta; ela definirá a etiqueta atual do etiquetador para a etiqueta copiada e também será salva na lista de etiquetas.

Além disso, você pode facilmente alterar a etiqueta atual dentre as etiquetas salvas segurando **Alt** (padrão; o nome do atalho é "Modificador 2 para itens da roda do mouse") e rolando a roda do mouse para cima ou para baixo.
