# O Cartão de Memória

<ItemImage id="memory_card" scale="4" />

O Cartão de Memória é usado para copiar e colar configurações entre [dispositivos](../ae2-mechanics/devices.md) do AE2, e vincular
[túneis P2P](p2p_tunnels.md). Ele também pode colar [cartões de melhoria](upgrade_cards.md) em dispositivos.

- Shift-clique com o botão direito para copiar as configurações ou gerar uma nova frequência de vinculação P2P.
- Clique com o botão direito para colar as configurações, os cartões de melhoria ou a frequência de vinculação.
