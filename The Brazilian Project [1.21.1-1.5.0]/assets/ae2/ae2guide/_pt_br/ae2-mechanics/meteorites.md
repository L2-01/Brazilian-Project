# Meteoritos

<GameScene zoom="4" background="transparent">
  <ImportStructure src="../assets/assemblies/meteor_interior.snbt" />
</GameScene>

Os meteoritos são o ponto de partida para usar o AE2. Eles fornecem materiais essenciais: [blocos de quartzo certus em brotamento](../items-blocks-machines/budding_certus.md)
de vários tipos e um <ItemLink id="mysterious_cube" /> no centro.

O [Começando](../getting-started.md) dá informações sobre o que fazer quando encontrar um.

## Encontrando Meteoritos

Os meteoritos são bem comuns e deixam crateras enormes no chão, então talvez você já tenha encontrado alguns. Se não, uma
<ItemLink id="meteorite_compass" /> apontará para o cubo misterioso mais próximo.
