# Controlador de Status do Provedor de Padrões

<BlockImage id="extendedae_plus:network_pattern_controller" scale="5" />

O **Controlador de Status do Provedor de Padrões** é uma unidade de controle central que permite gerenciar os modos de trabalho de todos os provedores de padrões da sua rede por uma única interface unificada.

## Interface e Operações

![Interface do Controlador de Status do Provedor de Padrões](../../picture/network_pattern_controller_en.png)

A UI do controlador oferece as seguintes opções de controle:

### Alternância de Modos
- **Alternar Modo de Bloqueio:** Ativa ou desativa globalmente o "Modo de Bloqueio" de todos os provedores de padrões.
- **Alternar Bloqueio Avançado:** Alterna globalmente o "Modo de Bloqueio Avançado".
- **Alternar Multiplicação Inteligente:** Ativa ou desativa globalmente o recurso de "Multiplicação Inteligente".

### Operações em Lote
- **Ativar Todos:** Um clique ativa os três recursos em todos os provedores de padrões da rede.
- **Desativar Todos:** Um clique desativa os três recursos em todos os provedores de padrões da rede.

## Como Usar
1. Coloque o **Controlador de Status do Provedor de Padrões** na sua rede ME.
2. Clique com o botão direito no controlador para abrir a interface de configuração.
3. Clique nos botões correspondentes para ajustar o status de todos os provedores de padrões globalmente, conforme suas necessidades de gerenciamento.

> **Nota:** Este controlador afeta **todos** os provedores de padrões da rede. Para configurar provedores individuais separadamente, ainda é preciso usar a UI de cada provedor.
