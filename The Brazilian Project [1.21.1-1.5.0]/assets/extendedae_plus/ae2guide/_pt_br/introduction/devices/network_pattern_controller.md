# Controlador de Status do Provedor de Padrões

<BlockImage id="extendedae_plus:network_pattern_controller" scale="5" />

O **Controlador de Status do Provedor de Padrões** é uma unidade de controle central que permite gerenciar os modos de trabalho de todos os provedores de padrões da sua rede através de uma única interface unificada.

## Interface e Operações

![Interface do Controlador de Status do Provedor de Padrões](../../picture/network_pattern_controller_en.png)

A interface do controlador oferece as seguintes opções de controle:

### Troca de Modo
- **Alternar Modo de Bloqueio:** Ativa ou desativa globalmente o "Modo de Bloqueio" para todos os provedores de padrões.
- **Alternar Bloqueio Avançado:** Alterna globalmente o "Modo de Bloqueio Avançado".
- **Alternar Duplicação Inteligente:** Ativa ou desativa globalmente o recurso de "Duplicação Inteligente".

### Operações em Lote
- **Ativar Tudo:** Um clique para ativar os três recursos em todos os provedores de padrões da rede.
- **Desativar Tudo:** Um clique para desativar os três recursos em todos os provedores de padrões da rede.

## Como Usar
1. Coloque o **Controlador de Status do Provedor de Padrões** na sua Rede ME.
2. Clique com o botão direito no controlador para abrir a interface de configuração.
3. Clique nos botões correspondentes para ajustar globalmente o status de todos os provedores de padrões conforme suas necessidades de gerenciamento.

> **Observação:** Este controlador afeta **todos** os provedores de padrões da rede. Para configurar provedores individualmente, você ainda precisa usar a interface de cada provedor.
