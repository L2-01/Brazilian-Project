# Super Cartão de Expansão do Provedor de Padrões Estendido

<ItemImage id="extendedae_plus:extended_pattern_provider_expansion_card_plus" scale="4" />

O **Super Cartão de Expansão do Provedor de Padrões Estendido** é um cartão de melhoria para os provedores de padrões estendidos do ExtendedAE. Cada cartão instalado desbloqueia uma página de padrões adicional, facilitando manter grandes configurações de automação organizadas num único provedor.

## Função e Efeitos

- **Página de padrões extra:** Cada cartão desbloqueia **1 página adicional** de espaços de padrão.
- **Capacidade de espaços:** Cada página contém **36 espaços de padrão**.
- **Limite de instalação:** Até **3 cartões** podem ser instalados num provedor suportado.
- **Capacidade máxima:** Com 3 cartões instalados, um provedor de padrões estendido pode usar **4 páginas / 144 espaços de padrão** no total.

## Dispositivos Suportados

- Provedor de Padrões ME Estendido
- Parte de Provedor de Padrões ME Estendido

## Proteção de Remoção

Se remover um cartão de expansão fizer as páginas desbloqueadas restantes não comportarem os padrões atuais, o cartão não poderá ser removido. Mova ou remova primeiro os padrões das páginas mais altas e tente remover o cartão novamente.

> **Nota:** Este cartão só expande as páginas de padrões dos provedores de padrões estendidos do ExtendedAE. Ele não aumenta a capacidade de padrões do Provedor de Padrões vanilla do AE2.
