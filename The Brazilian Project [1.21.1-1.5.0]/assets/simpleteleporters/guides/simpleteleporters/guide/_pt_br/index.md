# Simple Teleporters

Boas-vindas ao Simple Teleporters! Este mod oferece mecânicas de teletransporte fáceis de usar para o Minecraft.

## Recursos

<Row>
<Column>

### Rede de Teletransportadores

Crie uma rede de blocos de <ItemLink id="simpleteleporters:teleporter" /> conectados por itens de <ItemLink id="simpleteleporters:ender_shard" /> para viajar rapidamente entre locais. Melhore para um <ItemLink id="simpleteleporters:enhanced_ender_shard" /> para viagens entre dimensões!

</Column>
<Column>

### Teletransporte Pessoal

Use o <ItemLink id="simpleteleporters:hearth_crystal" /> para salvar um local de casa pessoal e teletransportar-se de volta a ele de qualquer lugar.

</Column>
</Row>
