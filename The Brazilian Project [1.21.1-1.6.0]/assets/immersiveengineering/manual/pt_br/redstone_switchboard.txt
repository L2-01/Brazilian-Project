Comutador de Redstone
Conexões significativas
Ao trabalhar com múltiplas redes de fio de redstone, conectar cores individuais entre si pode acabar exigindo muito espaço.<br>
O comutador de redstone resolve esse problema permitindo que qualquer sinal de uma rede seja retransmitido para outra, com as cores sendo livremente remapeadas no caminho.<br>
Os sinais só passam numa direção: esquerda -> direita quando se está de frente para o comutador.<br>
Além disso, o comutador possui inversores analógicos para todos os sinais, permitindo enviar à rede de saída o inverso do sinal de entrada.<np>
Para configurar o comutador, use a Chave de Fenda de Engenheiro para abrir a interface. Clique em qualquer soquete de entrada para começar a conectar um cabo ali, depois clique num soquete de saída para finalizar a conexão.<br>
Opcionalmente, alterne o botão vermelho "inverter" em qualquer painel de saída — mas note que a inversão só tem efeito se houver uma conexão indo para aquela saída.
