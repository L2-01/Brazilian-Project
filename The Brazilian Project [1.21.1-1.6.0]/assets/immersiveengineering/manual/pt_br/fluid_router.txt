Roteador de Fluidos
Leite vai à esquerda, ácido à direita
<&recipe>O Roteador de Fluidos funciona como o <link;item_router;Roteador de Itens;start>. Fluidos que entram são redistribuídos com base nos filtros de seus lados.<br>
Clicar com um balde ou outro recipiente de fluido nos espaços da GUI configura o filtro para aquele fluido.<np>
Quando fluidos são canalizados para o roteador, eles são roteados para uma saída cujo filtro combine com o fluido ou, se nenhum filtro combinar, para uma saída sem filtro. Se não houver rota disponível ou válida, nenhum fluido será aceito.<br>
Os botões acima de cada filtro podem ser usados para fazer o roteador respeitar ou ignorar os componentes de dados do fluido, como o tipo de poção.
