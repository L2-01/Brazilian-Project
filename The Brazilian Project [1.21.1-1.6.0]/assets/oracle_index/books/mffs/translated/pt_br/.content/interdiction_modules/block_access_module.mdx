# Módulo de Bloqueio de Acesso

O Módulo de Bloqueio de Acesso é um módulo opcional para a [](@mffs:interdiction_matrix).
Ele permite à Matriz inibir a capacidade de um jogador de clicar com o botão direito num bloco e acessar sua tela GUI.

<PrefabObtaining />

## Efeito

Se um jogador não autorizado tentar clicar com o botão direito num bloco ou máquina localizada dentro do alcance de ação de uma
Matriz de Interdição (equipada com o Módulo de Bloqueio de Acesso), não lhe será permitido abrir sua GUI. Como esperado, blocos
ou máquinas fora da área de ação podem ser usados normalmente.
