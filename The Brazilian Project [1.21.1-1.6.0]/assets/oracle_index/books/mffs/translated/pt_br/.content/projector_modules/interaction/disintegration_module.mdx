# Módulo de Desintegração

O Módulo de Desintegração pode ser usado num [](@mffs:projector) para alterar o efeito que um campo de força tem sobre o seu
redor. Colocar um Módulo de Desintegração nos espaços de matriz de um Projetor fará o campo que ele gera
quebrar quaisquer blocos que o estejam obstruindo. Blocos quebrados caem como itens e podem ser coletados.

<PrefabObtaining />

## Uso

O Módulo de Desintegração é compatível com todos os modos de projetor e pode ser usado para inverter o efeito do 
[](mffs:stabilization_module).
Adicionar [Módulos de Velocidade](@mffs:speed_module) a um Projetor permite desintegrar vários blocos de uma vez.
Ele também pode ser combinado com um [](@mffs:collection_module) para coletar automaticamente os blocos quebrados.
