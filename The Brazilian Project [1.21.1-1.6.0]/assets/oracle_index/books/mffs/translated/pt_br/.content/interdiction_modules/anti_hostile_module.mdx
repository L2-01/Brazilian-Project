# Módulo Anti-Hostil

O Módulo Anti-Hostil é um módulo opcional para a [](@mffs:interdiction_matrix).

<PrefabObtaining />

## Efeito

Com este módulo instalado, a Matriz consegue detectar automaticamente criaturas hostis que entram em seu alcance de varredura e
os matará — quase instantaneamente.

Jogadores e entidades não hostis como aldeões e animais não são prejudicados.
