# Módulo de Fusão de Campo

O Módulo de Fusão de Campo pode ser colocado nos espaços de matriz de um [](@mffs:projector) para fundir dois ou mais campos projetados.

O módulo cortará quaisquer blocos projetados que se sobreponham a outro campo de força. Vários campos de força com este
módulo serão então fundidos perfeitamente em um só.
