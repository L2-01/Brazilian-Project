# Módulo de Escala

O Módulo de Escala pode ser colocado nos espaços de melhoria de várias máquinas MFFS para ampliar suas capacidades de distância.

Seus efeitos variam conforme a máquina, mas mais comumente incluem:
- Aumentar o tamanho do campo de força
- Aumentar a área de interdição
- Aumentar o impulso de combustível de um [](@mffs:coercion_deriver)
