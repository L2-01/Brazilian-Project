# Módulo Anti-Geração

O Módulo Anti-Geração é um módulo opcional para a [](@mffs:interdiction_matrix).

<PrefabObtaining />

## Efeito

Com este módulo instalado, a Matriz impedirá que entidades hostis ou amigáveis surjam dentro de sua área de ação.

Se um jogador possuir um ovo gerador, ficar logo fora do alcance de ação da Matriz lhe permitirá gerar a entidade
dentro da região protegida.
