# Módulo de Rotação

O Módulo de Rotação pode ser colocado nos espaços de campo do [](@mffs:projector) para girar o campo projetado.

Você pode mover o campo de força nos eixos x, y ou z colocando Módulos de Rotação no espaço respectivo de cada eixo.

- EAST, WEST — Ajustam o Yaw
- UP, DOWN — Ajustam o Pitch
- SOUTH, NORTH — Ajustam o Roll
