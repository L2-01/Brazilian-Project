# Módulo Anti-Pessoal

O Módulo Anti-Pessoal é um módulo opcional para a [](@mffs:interdiction_matrix).

<PrefabObtaining />

## Efeito

Com este módulo instalado, a Matriz detectará automaticamente jogadores não autorizados que entram em seu alcance de ação e
os matará — quase instantaneamente.

Criaturas amigáveis e hostis não são prejudicadas.
