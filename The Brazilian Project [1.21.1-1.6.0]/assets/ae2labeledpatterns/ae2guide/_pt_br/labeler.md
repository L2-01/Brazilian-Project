# Etiquetador
<ItemImage id="ae2labeledpatterns:labeler" scale="4"></ItemImage>
A Etiquetador é uma ferramenta para gerenciar etiquetas e aplicar ou limpar etiquetas em provedores de padrões.

## GUI
Clique com o botão direito no ar para abrir a GUI da etiquetador.

Na GUI, na área central você pode ver um campo de entrada para digitar um etiqueta e um botão para salvar o etiqueta. Certifique-se de salvar o etiqueta após editá-lo.
Na barra de ferramentas esquerda, você pode alternar o modo de entrada de bloco para controlar se o campo de entrada está ativado ou não.
Você também pode abrir o botão da lista de etiquetas para mostrar todos os etiquetas que esta etiquetador salvou.
Na GUI da lista de etiquetas, você pode selecionar qualquer etiqueta para ser o etiqueta atual e excluir qualquer etiqueta de que não precise mais.

Além disso, você pode ligar ou desligar a função de renomear clicando no botão de renomear.
Quando a função de renomear está ativada, toda operação afetará o nome em vez do etiqueta.
Por exemplo, se você definir o etiqueta como "Máquina" e a função de renomear estiver ativada,
ao aplicar o etiqueta num provedor de padrões,
ele renomeará o provedor de padrões para "Máquina" em vez de aplicar o etiqueta "Máquina".

## No Jogo
Normalmente, para aplicar um etiqueta, segure a etiquetador na mão e faça Shift+clique-direito num bloco de provedor de padrões;
você receberá uma mensagem no chat confirmando que o etiqueta foi aplicado.
Se estiver usando um mod de dicas como o Jade,
você poderá ver as informações do etiqueta aplicado na dica do bloco do provedor de padrões.

A Etiquetador tem 5 modos, que podem ser alternados segurando **Shift** (padrão, nome do atalho "mouse wheel item modifier 1") e rolando a roda do mouse para cima ou para baixo.
Os modos são:
1. **Definir Único**: modo padrão, Shift+clique-direito num bloco de provedor de padrões para aplicar o etiqueta
2. **Limpar Único**: Shift+clique-direito num bloco de provedor de padrões para limpar o etiqueta
3. **Definir Área**: Shift+clique-direito em dois blocos para definir uma área; então todos os blocos na área serão verificados e receberão o etiqueta atual
4. **Limpar Área**: Shift+clique-direito em dois blocos para definir uma área; então todos os blocos na área serão verificados e limpos
5. **Copiar**: Shift+clique-direito num bloco de provedor de padrões para copiar seu etiqueta; isso definirá o etiqueta atual da etiquetador para o etiqueta copiado e também o salvará na lista de etiquetas.

Além disso, você pode mudar facilmente o etiqueta atual de acordo com os etiquetas salvos segurando **Alt** (padrão, nome do atalho "mouse wheel item modifier 2") e rolando a roda do mouse para cima ou para baixo.
