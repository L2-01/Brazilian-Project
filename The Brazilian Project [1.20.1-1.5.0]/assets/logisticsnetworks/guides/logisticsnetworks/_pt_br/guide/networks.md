# Redes

Uma rede é apenas um grupo de nós. As transferências só acontecem dentro de uma mesma rede.

Você escolhe a rede na tela do nó.

1. Coloque um nó.
2. Abra-o com a chave-inglesa no modo Chave.
3. Crie um novo nome de rede, ou escolha uma existente.

O que acontece depois disso:

1. O nó armazena o id e o nome da rede.
2. O registro mantém a lista de nós daquela rede.
3. Redes vazias são deletadas automaticamente.

Um nó sem rede não transfere nada.
