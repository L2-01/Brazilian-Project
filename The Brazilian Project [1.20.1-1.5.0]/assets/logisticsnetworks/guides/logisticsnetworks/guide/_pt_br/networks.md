# Redes

Uma rede é só um grupo de nós. Transferências só acontecem dentro de uma única rede.

Você escolhe a rede na tela do nó.

1. Coloque um nó.
2. Abra-o com a Chave-Inglesa no modo Chave.
3. Crie um nome de rede novo, ou escolha um existente.

O que acontece depois disso:

1. O nó grava o id e o nome da rede.
2. O registro mantém a lista de nós daquela rede.
3. Redes vazias são apagadas automaticamente.

Um nó sem rede não transfere nada.
