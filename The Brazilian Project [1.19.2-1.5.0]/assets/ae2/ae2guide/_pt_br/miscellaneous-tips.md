### Como os Itens são Colocados

Itens entrando na rede começarão pelo armazenamento de maior prioridade, como
seu primeiro destino; no caso de dois armazenamentos terem a mesma prioridade,
se um já contiver o item, eles preferirão aquele armazenamento sobre qualquer
outro. Quaisquer células na lista de permissões serão tratadas como se já contivessem o item
quando estiverem no mesmo grupo de prioridade que outros armazenamentos.

### Melhorando Células de Armazenamento

Se você tiver uma célula de armazenamento VAZIA de qualquer nível, pode remover o
componente de dentro da cápsula segurando-a na mão e usando shift + clique direito,
assim você pode guardá-lo ou usá-lo para fazer células maiores. Isso também
lhe devolve uma cápsula de célula de armazenamento vazia para inserir outro componente.

### Terminais / Monitores Coloridos

Quando você coloca um <ItemLink id="terminal"/> ou
outros monitores num cabo, eles assumem a cor daquele cabo — então, se o cabo for
azul, a tela da parte colocada também será.

### Conexões de Rede de Mão Única

Você pode ligar um Ponto de Armazenamento a uma interface de uma rede separada para criar
uma conexão de mão única, permitindo criar redes públicas / privadas. Isso
exige que a Interface esteja desconfigurada; se a interface estiver configurada para
armazenar itens, ela verá os itens no inventário em vez disso.

### Girando Blocos

Você pode girar a maioria dos blocos usando uma chave compatível com Buildcraft, como
a <ItemLink id="certus_quartz_wrench"/>.

### Definindo Prioridade

Você pode definir Prioridades de Armazenamento no <ItemLink
id="chest"/>, no <ItemLink
id="drive"/> ou no <ItemLink
id="storage_bus"/> na aba Prioridade, no canto
superior direito. Prioridades maiores são mais importantes que as menores e, por
padrão, todos os armazenamentos vêm com 0.

### Removendo Blocos / Partes

Você pode usar Shift + clique direito com uma chave compatível com Buildcraft e ela
desmontará o bloco ou parte do AE e o derrubará para você. Isso é muito útil
com partes, pois se você usar uma picareta, ela derrubará qualquer cabo e partes do
bloco; usar a chave permite retirar uma única parte.
