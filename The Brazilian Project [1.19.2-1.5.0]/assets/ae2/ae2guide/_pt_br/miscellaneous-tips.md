### Como os Itens são Colocados

Itens que entram na rede começam pelo armazenamento de maior prioridade como
primeiro destino; no caso de dois armazenamentos com a mesma prioridade,
se um já contém o item, ele será preferido sobre qualquer
outro. Quaisquer células com lista de permissões serão tratadas como se já contivessem o item
quando estiverem no mesmo grupo de prioridade de outros armazenamentos.

### Aprimorando Células de Armazenamento

Se você tiver uma célula de armazenamento VAZIA de qualquer nível, pode remover o
componente da cápsula segurando-a na mão e Shift+clicando com o botão direito, podendo
guardá-lo ou usá-lo para fazer células maiores. Isso também devolve a
cápsula de armazenamento vazia para inserir outra célula.

### Terminais / Monitores Coloridos

Quando você coloca um <ItemLink id="terminal"/> ou
outros monitores num cabo, eles assumem a cor daquele cabo — se o cabo for
azul, a tela da parte colocada também será.

### Conexões de Rede de Mão Única

Você pode ligar um Ponto de Armazenamento a uma interface numa rede separada para
criar uma conexão de mão única, permitindo criar redes públicas / privadas. Isso
exige que a Interface esteja desconfigurada; se ela estiver configurada para
armazenar itens, o ponto verá os itens no inventário.

### Girando Blocos

Você pode girar a maioria dos blocos usando uma Chave Inglesa compatível com Buildcraft, como
a <ItemLink id="certus_quartz_wrench"/>.

### Definindo Prioridade

Você pode definir Prioridades de Armazenamento no <ItemLink
id="chest"/>, <ItemLink
id="drive"/> ou <ItemLink
id="storage_bus"/> na Aba de Prioridade, no canto superior
direito. Prioridades maiores são mais importantes que as menores e, por
padrão, todos os armazenamentos são definidos como 0.

### Removendo Blocos / Partes

Você pode Shift + Clicar com o botão direito com uma Chave Inglesa compatível com Buildcraft para
desmontar o Bloco ou Parte do AE e largá-lo para você; isso é mais útil
com Partes, pois usar uma picareta largaria todos os cabos e partes do
bloco — usar uma chave permite retirar uma única parte.
