![Uma imagem de âncoras para cabos num cabo de vidro.](../../assets/large/cable_anchor.png)

Pequenos espigões decorativos montados em cabos que você pode usar para criar escadas com cabos, ou fazer o cabo parecer
conectado às paredes ao redor. Também são usados para fabricar <ItemLink id="facade"/>.

Âncoras para cabos impedem que conexões se formem no lado em que estão montadas.
