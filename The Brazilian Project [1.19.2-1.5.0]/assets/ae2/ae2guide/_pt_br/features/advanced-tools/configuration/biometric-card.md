Codifica a identidade de um jogador no cartão; clique com o botão direito em outro jogador, ou use
shift + clique para definir você mesmo. Se você codificar o mesmo jogador duas vezes, o cartão é
limpo. Um cartão limpo representa os outros usuários como o "padrão".

Quando o <ItemLink id="biometric_card"/> foi
codificado, ele mostra um Identicon para o usuário, para que você diferencie os
cartões; cada cartão de um mesmo usuário terá o mesmo Identicon.
