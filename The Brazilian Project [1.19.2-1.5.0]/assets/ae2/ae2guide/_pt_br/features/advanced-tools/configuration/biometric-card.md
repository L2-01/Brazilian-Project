Codifica a identidade de um jogador no cartão: clique com o botão direito em outro jogador, ou Shift+clique
para definir você mesmo. Se você codificar o mesmo jogador duas vezes, o cartão será limpo.
Um cartão limpo representa os outros usuários como o "padrão".

Quando o <ItemLink id="biometric_card"/> tiver
sido codificado, ele exibirá um Identicon do usuário para você distinguir os cartões;
cada cartão do mesmo usuário terá o mesmo Identicon.
