O <ItemLink id="formation_plane"/> é uma parte
feita para colocar ou largar qualquer item inserido na [Rede ME](../../me-network.md).
Ele funciona como armazenamento, de forma semelhante a um <ItemLink id="storage_bus"/>, então itens
adicionados à rede são largados ou colocados passivamente. Você pode configurar
o <ItemLink id="formation_plane"/> para indicar itens específicos
que ele deve colocar. Os itens são colocados instantaneamente quando entram na rede.

Exige um [canal](../channels.md) para funcionar.
