Célula de Armazenamento de nível mais baixo, que pode conter 1.024 bytes de armazenamento.

1.024 bytes de armazenamento comportam 127 pilhas de um único item, ou 65
pilhas ao conter 63 itens diferentes.

A Célula de Armazenamento de 1k usa 8 bytes de dados para armazenar um único tipo. [Clique aqui
para detalhes sobre como a matemática de armazenamento funciona.](../../storage-cells.md)

Quando colocada num gabinete ou baú, consome 0,5 AE/t.

Deve estar num <ItemLink id="drive"/> ou <ItemLink id="chest"/> para ser usada.

Você pode remover o <ItemLink id="cell_component_1k"/> esvaziando completamente a célula de armazenamento e usando shift + clique direito
enquanto a segura.

As configurações podem ser alteradas na <ItemLink id="cell_workbench"/>.
