Célula de Armazenamento de nível mais baixo, que pode conter 1.024 bytes de armazenamento.

1.024 bytes de armazenamento comportam 127 pacotes de um único item, ou 65
pacotes enquanto guarda 63 itens diferentes.

A Célula de Armazenamento 1k usa 8 bytes de dados para armazenar um único tipo. [Clique
aqui para detalhes de como funciona a matemática de armazenamento.](../../storage-cells.md)

Quando colocada num gabinete ou baú, consome 0,5 AE/t.

Precisa estar num <ItemLink id="drive"/> ou <ItemLink id="chest"/> para ser utilizável.

Você pode remover o <ItemLink id="cell_component_1k"/> esvaziando totalmente a célula de armazenamento e Shift+clicando
com ela na mão.

As configurações podem ser alteradas na <ItemLink id="cell_workbench"/>.
