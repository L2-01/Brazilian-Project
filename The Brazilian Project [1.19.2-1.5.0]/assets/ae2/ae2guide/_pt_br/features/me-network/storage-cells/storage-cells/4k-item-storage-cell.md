Célula de Armazenamento de nível baixo, que pode conter 4.096 bytes de armazenamento.

4.096 bytes de armazenamento comportam 508 pacotes de um único item, ou 260
pacotes enquanto guarda 63 itens diferentes.

A Célula de Armazenamento 4k usa 32 bytes de dados para armazenar um único tipo. [Clique
aqui para detalhes de como funciona a matemática de armazenamento.](../../storage-cells.md)

Quando colocada num gabinete ou baú, consome 1,0 AE/t.

Precisa estar num <ItemLink id="drive"/> ou <ItemLink
id="chest"/> para ser utilizável.

Você pode remover o <ItemLink
id="cell_component_4k"/> esvaziando totalmente a
célula de armazenamento e Shift+clicando com ela na mão.
