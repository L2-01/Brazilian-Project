Célula de Armazenamento de nível baixo, que pode conter 4.096 bytes de armazenamento.

4.096 bytes de armazenamento comportam 508 pilhas de um único item, ou 260
pilhas ao conter 63 itens diferentes.

A Célula de Armazenamento de 4k usa 32 bytes de dados para armazenar um único tipo. [Clique aqui
para detalhes sobre como a matemática de armazenamento funciona.](../../storage-cells.md)

Quando colocada num gabinete ou baú, consome 1,0 AE/t.

Deve estar num <ItemLink id="drive"/> ou <ItemLink
id="chest"/> para ser usada.

Você pode remover o <ItemLink
id="cell_component_4k"/> esvaziando completamente a
célula de armazenamento e usando shift + clique nela na sua mão.
