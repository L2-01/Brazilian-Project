## Monitor de Armazenamento

O <ItemLink id="storage_monitor"/> é uma forma
simples de ver o nível atual de um item específico. Há várias
interações para modificá-lo.

| Ação                              | Efeito                                                                |
| --------------------------------- | --------------------------------------------------------------------- |
| Clique direito com item           | Exibe a quantidade atual armazenada daquele item, se não estiver travado. |
| Clique direito com a mão vazia    | Redefine a exibição, se não estiver travada.                          |
| Shift+Clique direito com mão vazia| Alterna a trava.                                                      |
| Clique direito com chave inglesa  | Gira o monitor, se travado e no chão ou no teto.                      |

## Monitor de Conversão

O <ItemLink id="conversion_monitor"/> é a
versão aprimorada do <ItemLink
id="storage_monitor"/>. Ele adiciona a capacidade de
retirar itens da [Rede ME](../me-network.md) ou armazená-los diretamente nela.

Além das interações do monitor de armazenamento, os monitores de conversão suportam as seguintes ações:

| Ação                        | Efeito                                                                  |
| --------------------------- | ----------------------------------------------------------------------- |
| Clique esquerdo             | Extrai um pacote do item exibido para o seu inventário.                |
| Clique direito com item     | Insere o item segurado na rede.                                        |
| Clique direito com mão vazia| Insere na rede todo o item exibido presente no seu inventário.         |
