## Monitor de Armazenamento

O <ItemLink id="storage_monitor"/> é uma forma
simples de ver a quantidade atual de um item específico. Existem várias
interações para modificá-lo.

| Ação                              | Efeito                                                                  |
| --------------------------------- | ----------------------------------------------------------------------- |
| Clique direito com item           | Mostra a quantidade atualmente armazenada daquele item, se não estiver travado. |
| Clique direito com a mão vazia    | Reinicia a exibição, se não estiver travada.                            |
| Shift + clique direito com a mão vazia | Alterna a trava.                                                    |
| Clique direito com chave          | Gira o monitor, se estiver travado e no chão ou no teto.               |

## Monitor de Conversão

O <ItemLink id="conversion_monitor"/> é a
versão melhorada do <ItemLink
id="storage_monitor"/>. Ele adiciona a capacidade de
retirar de ou armazenar itens diretamente na [Rede ME](../me-network.md).

Além das interações do monitor de armazenamento, monitores de conversão suportam as seguintes ações:

| Ação                        | Efeito                                                                    |
| --------------------------- | ------------------------------------------------------------------------- |
| Clique esquerdo             | Extrai uma pilha do item exibido para o seu inventário.                   |
| Clique direito com item     | Insere o item segurado na rede.                                           |
| Clique direito com a mão vazia | Insere todo o item exibido do seu inventário na rede.                  |
